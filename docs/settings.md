# 設定と保存されるもの

MarkView に設定画面はありません。**操作した結果がそのまま設定になります。**

このドキュメントは「何が保存され、何が保存されないか」を明らかにするためのものです。

## 保存されるもの

| 項目 | 既定値 |
| --- | --- |
| テーマ | OS の設定に従う |
| 表示倍率 | 100 %（50〜300 %） |
| アウトラインペインの表示状態 | 表示 |
| ファイルツリーペインの表示状態 | 非表示 |
| アウトラインペインの幅 | 240 |
| ファイルツリーペインの幅 | 260 |
| ウィンドウの幅・高さ | 1280 × 860 |
| ウィンドウの最大化状態 | 通常 |

いずれも**快適性のための値**だけです。消えても困らないものに限っています。

### テーマだけ扱いが特別です

初回起動時は OS の設定に従います。この段階では設定に何も書きません。

**一度自分で切り替えると、その時点で「利用者が選んだ」ことになり**、以後は OS の設定が
変わっても追従しなくなります。追従に戻したい場合は、設定ファイルを消してください
（[消したいとき](#消したいとき)）。

### ウィンドウの位置は保存しません

大きさと最大化状態は保存しますが、**位置は保存も復元もしません。** 起動時は常に
プライマリモニタの中央に開きます。

モニタ構成が変わったときに、画面外に開いて操作できなくなる事故を避けるためです。

## 保存されないもの

MarkView は**閲覧の痕跡をディスクのどこにも書きません**。

| 保存しないもの | 理由 |
| --- | --- |
| 開いたファイルのパス | 何を読んだかは業務上の情報になりうる |
| ファイルツリーの起点 | 同上 |
| 表示履歴（`Alt+←` で戻れる範囲） | 同上。アプリを終了すると消える |
| 検索した語 | 同上 |
| ウィンドウの位置 | 上記のとおり |
| 最近使ったファイル | **そもそも機能として持たない** |

「最近開いたファイル」の一覧はありません。便利さより、痕跡を残さないことを優先しています。

## 保存先

設定は **OS のテンポラリディレクトリにだけ**書きます。

| OS | パス |
| --- | --- |
| Windows | `%TEMP%\MarkView\config.json`（通常は `C:\Users\<user>\AppData\Local\Temp\MarkView\`） |
| Linux | `$TMPDIR/MarkView-<uid>/config.json`。`$TMPDIR` が無ければ `/tmp/MarkView-<uid>/config.json` |

- **`%APPDATA%` にも `~/.config` にも、レジストリにも書きません。**
- Linux の `/tmp` は全ユーザ共有のため、ディレクトリ名にユーザ ID を含め、
  ディレクトリを `0700`、ファイルを `0600` にします。他のユーザの設定は読み書きしません。
- 形式は人が読める JSON です。
- 書き込みは「一時ファイルへ書いてからリネーム」で行います。書き込み中に異常終了しても
  設定は壊れません。

### 中身の例

```json
{
  "theme": "dark",
  "zoom": 110,
  "outlineVisible": true,
  "fileTreeVisible": false,
  "outlineWidth": 240,
  "fileTreeWidth": 260,
  "windowWidth": 1280,
  "windowHeight": 860,
  "windowMaximized": false
}
```

**ファイルパスに類するものは 1 つも含まれません。**

## 設定が無い・壊れているとき

テンポラリディレクトリは OS のクリーンアップや再起動（特に Linux の `/tmp`）で
消えることがあります。そのため、次のいずれの場合も**エラーにせず既定値で起動します**。

- 設定ファイルが無い
- JSON として読めない（壊れている）
- 一部の項目だけが無い → 足りない分は既定値
- 値が範囲外（倍率が 500、ペイン幅が負など）→ 既定値に丸める
- 設定ディレクトリを作れない・書き込めない → 設定なしで動き続ける

最後の場合、その回の変更が次回に引き継がれないだけです。エラー表示は出ません。

> [!NOTE]
> 保存先をテンポラリにしている以上、設定は「消えても差し支えのない情報」に限られます。
> この前提があるからこそ、開いていたファイルのような**業務上の意味を持つ情報を
> 保存対象に含めない**設計が成り立っています。

## 消したいとき

上の表のディレクトリごと削除してください。次回は既定値で起動します。

```powershell
Remove-Item -Recurse "$env:TEMP\MarkView"
```

```sh
rm -rf "${TMPDIR:-/tmp}/MarkView-$(id -u)"
```

テーマを OS 設定への追従に戻したい場合も、これで戻ります。

## ネットワークについて

MarkView は**自分からネットワークへ接続しません**。

- 更新確認、テレメトリ、クラッシュレポート送信は**実装していません**。
- Mermaid・KaTeX・フォント・アイコンはすべて実行ファイルに埋め込んであります。
  オフラインでも図と数式は欠けません。
- 唯一の例外は、文書が `http://` `https://` の画像を参照している場合です。
  このときだけ WebView がその画像を取りに行きます。

## システムに残すもの

インストーラを持たず、レジストリにも `~/.local/share/applications` にも書きません。
`.md` の関連付けも自分では登録しません（[使い方](./usage.md#md-を-markview-に関連付ける)）。

**アンインストールは、展開したフォルダと上記の設定ディレクトリを消すだけです。**
