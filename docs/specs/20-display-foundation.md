# 20. 表示仕様: デザイン基礎

> 索引: [README](README.md) | 表示仕様: **20** / [21](21-display-components.md) / [22](22-display-states.md)

本文書から始まる表示仕様書（`DSP-nnn`）は、要求仕様書が定めた画面要求（`UI-nnn`）と描画要求（`MD-nnn`）に対して、**どう見えるか**を具体値で定める。構造とクラス名は実装仕様書（[12](12-impl-frontend.md)）で定めており、本文書はそこに色・寸法・書体を与える。

## 20.1 本文書群の位置づけ

### DSP-001: 値の正 **MUST**

- 本文書に記す色・寸法は**策定時点の代表値**である。本文の描画（`.markdown-body` 配下）については、同梱する `github-markdown-css` の定義を正とし、値が食い違う場合は同梱物の定義を優先する（MD-001）。
- アプリ自身の UI（ツールバー・ペイン・ステータス・検索バー・ダイアログ）については、**本文書の値を正**とする。本文と地続きに見えるよう、同じトークン体系から色を採る。
- 資産の更新（BR-043）で本文の配色が変わった場合、アプリ UI 側のトークンも追随させ、両者の色がずれた状態を放置しない。

### DSP-002: 実装との対応 **MUST**

本文書の値は `frontend/css/tokens.css` に CSS カスタムプロパティとして実装する（IMP-200）。個々のコンポーネントの CSS はトークンを参照し、色コードを直接書かない。

### DSP-011: テーマの適用機構 **MUST**

```css
:root { /* Light を既定として定義 */ }
[data-theme="dark"] { /* Dark で上書き */ }
```

- 切り替えは `#app` の `data-theme` 属性のみで行う（IMP-243）。要素の再生成や本文の再変換を伴わない（UI-105）。
- `prefers-color-scheme` に直接反応する CSS を書かない。OS 設定の反映は起動時に Go 側が解決した値で行う（FR-071, IMP-303）。両方に反応させると、設定値と OS 設定が食い違ったときに表示が揺れる。
- **`color-scheme` をテーマに合わせて宣言する。** タスクリストのチェックボックス（MD-022）のように OS が描く部品は、色を CSS のトークンで指定できない。この宣言がないと Dark でも明るい配色のまま浮く。
- トランジションを色に対して掛けない。テーマ切り替えは即時に完了させる（UI-105 の「ちらつきを発生させない」）。

### DSP-012: 本文の配色 **MUST**

`.markdown-body` 配下は `github-markdown-css` の定義に従う（DSP-001）。同梱物が定義する CSS 変数と、本文書のトークンを以下のとおり対応させ、片方だけが変わることを防ぐ。

| github-markdown-css の変数 | 本文書のトークン |
| --- | --- |
| `--color-canvas-default` | `--canvas-default` |
| `--color-canvas-subtle` | `--canvas-subtle` |
| `--color-fg-default` | `--fg-default` |
| `--color-fg-muted` | `--fg-muted` |
| `--color-border-default` | `--border-default` |
| `--color-accent-fg` | `--accent-fg` |

`markdown.css` はこの 6 つを `.markdown-body` の上で定義し、本文の規則からはトークンではなくこちらを参照する。対応表を 1 か所に閉じ込めるためである。表に無い色（`--border-muted` など）はトークンを直接参照してよい。

> [!NOTE]
> **同梱物側の変数名は改称されている。** `github-markdown-css` は v5.9.0 の時点で `--fgColor-default` / `--bgColor-default` / `--fgColor-muted` / `--borderColor-default` / `--fgColor-accent` という名前へ移行しており、上の表が挙げる `--color-*` は既に使っていない。現在の `markdown.css` は同梱物のファイルを読み込まず書き起こしているため実害はないが、将来ファイルをそのまま読み込む形へ変える場合は、この表を新しい名前へ揃える必要がある。

| `.nf`, `.nx` | 関数名・識別子 | `#8250df` | `#d2a8ff` |

### DSP-014: アイコンの表示 **MUST**

UI-022 / IMP-203 を実装する。

| 項目 | 値 |
| --- | --- |
| 描画サイズ | 16 × 16 px |
| 色（通常） | `--fg-muted` |
| 色（ホバー・フォーカス） | `--fg-default` |
| 色（トグル ON） | `--accent-fg` |
| 色（無効） | `--fg-subtle` |
| 塗り | `fill: currentColor` |

### DSP-015: 重なり順 **MUST**

`z-index` は以下の値のみを使う。中間値を場当たりに追加しない。

| 値 | 対象 |
| --- | --- |
| `0` | 本文 |
| `10` | コピーボタン、リサイザ |
| `20` | 検索バー |
| `30` | ステータスの一時メッセージ |
| `40` | 状態画面 |
| `50` | 情報ダイアログのオーバーレイ |
| `60` | ドロップオーバーレイ |
| `70` | ツールチップ |

ドロップオーバーレイを高い位置に置くのは、ダイアログ表示中にファイルをドラッグした場合でもドロップ可能であることを示すためである（UI-070 の「ウィンドウ全体」）。ツールチップはさらに上に置く。どの文脈でもボタンの説明が隠れずに読めるようにするためで、ドラッグ中はツールチップ自体が表示されないため競合しない。

### DSP-016: フォーカス表示 **MUST**

- キーボード操作時のフォーカスリングを消さない（IMP-295）。
- 表現は `outline: 2px solid var(--accent-fg); outline-offset: -1px;` とする。
- `:focus-visible` を用い、マウスクリックによるフォーカスではリングを出さない。

### DSP-017: アプリケーションアイコン **MUST**

UI-025 を実装する。ツールバー内の単色アイコン（DSP-014）とは扱いが異なり、**テーマに追従せず、色を変えない固有の画像**である。

| 用途 | ファイル | 表示サイズ |
| --- | --- | --- |
| Windows 実行ファイル | `assets/icon.ico` | OS が用途に応じて内蔵サイズから選択（16 / 32 / 48 / 256 px を含めること） |
| ウィンドウ・タスクバー | Windows: `assets/icon.ico` / Linux: `assets/icon.png` | OS が選択 |
| 情報ダイアログ | `/appicon.png`（IMP-160 が配信） | 48 × 48 論理ピクセル |

- 情報ダイアログでは角丸を付けず、縦横比を維持して表示する。背景色を敷かない。
- **Light テーマと Dark テーマの双方で視認できる絵柄であること。** 白背景・黒背景のどちらに置いても輪郭が消えないよう、単色の塗り潰しや極端に明るい/暗い配色を避ける。テーマごとに画像を切り替える仕組みは持たない。
- 高 DPI 環境で拡大されるため、`icon.png` は 256 × 256 px 以上の解像度を持つこと（DSP-381）。
- 文書未表示時の案内画面には使用しない（DSP-181）。そこでは行動を示す `icon-open` を用いる。

## 20.3 タイポグラフィ（DSP-020 系）

### DSP-020: 書体と字送り **MUST**

MD-010 / MD-011 を実装する。

| 用途 | フォントスタック | サイズ | 行の高さ |
| --- | --- | --- | --- |
| 本文 | `-apple-system, BlinkMacSystemFont, "Segoe UI", "Noto Sans", Helvetica, Arial, "Yu Gothic UI", Meiryo, "Noto Sans CJK JP", sans-serif` | 16 px | 1.6 |
| コード | `ui-monospace, SFMono-Regular, "SF Mono", Menlo, Consolas, "Liberation Mono", "Noto Sans Mono", monospace` | 13.6 px（本文の 85 %） | 1.45 |
| アプリ UI（ツールバー・ペイン） | 本文と同じスタック | 13 px | 1.5 |
| ステータス領域 | 本文と同じスタック | 12 px | 1.4 |
| ペイン見出し（`Files` / `Outline`） | 本文と同じスタック | 11 px（大文字・字間 0.04em） | 1.4 |

### DSP-021: 表示倍率の適用範囲 **MUST**

FR-081 / IMP-242 を実装する。

```css
.markdown-body { font-size: calc(16px * var(--zoom, 100) / 100); }
```

- `--zoom` は `#markdown` に設定する。ツールバー・ペイン・ステータスには影響させない（FR-081）。
- 本文内の余白・コードブロック・表の寸法は `em` で定義し、倍率に追随させる。
- 画像とMermaid 図は本文幅（`max-width: 100%`）に従うため、結果として倍率に追随する。

### DSP-022: 見出しの階層 **MUST**

MD-020 を実装する。値は本文サイズ（`1em` = 16 px）に対する相対値。

| 要素 | サイズ | 上マージン | 下マージン | 下線 |
| --- | --- | --- | --- | --- |
| `h1` | 2em | 24px | 16px | あり（`--border-muted`） |
| `h2` | 1.5em | 24px | 16px | あり（`--border-muted`） |
| `h3` | 1.25em | 24px | 16px | なし |
| `h4` | 1em | 24px | 16px | なし |
| `h5` | 0.875em | 24px | 16px | なし |
| `h6` | 0.85em（`--fg-muted`） | 24px | 16px | なし |

### DSP-023: 見出しのアンカーアイコン **SHOULD**

MD-020 / IMP-227 を実装する。フックは `a.heading-anchor`。

| 項目 | 値 |
| --- | --- |
| 位置 | 見出しの**左外側**。`h1`〜`h6` に `position: relative` を与え、`position: absolute` で `left: -1.2em` に置く |
| 大きさ | `.icon` と同じ 16 × 16（DSP-014）。倍率には追随しない |
| 色 | `--fg-muted` |
| 既定 | `opacity: 0` |
| 表示する条件 | 見出しの `:hover`、および `:focus-within`（キーボード操作でも出す。DSP-016） |
| 遷移 | `opacity` のみ 0.1 秒（DSP-050）。`prefers-reduced-motion` では即時（DSP-051） |

- **本文の折り返しに影響させない。** 絶対配置とし、見出しのテキストの開始位置を動かさない。
- 幅が足りない環境では枠外へはみ出すため、`#markdown` に `overflow-x` を新たに与えない（UI-050 の「横スクロールを発生させない」）。**はみ出した分は見えなくてよい。** アンカーは補助であり、見えないことで文書が読めなくなるものではない。
- 見出しにマウスを乗せていない間は、**空白も占有しない**（絶対配置のため）。

## 20.4 寸法（DSP-030 系）

### DSP-030: レイアウト寸法 **MUST**

UI-010 / UI-011 / UI-023 / UI-030 / UI-040 / UI-050 / UI-060 を実装する。単位はすべて論理ピクセル。

| 対象 | 値 | 根拠 |
| --- | --- | --- |
| ウィンドウ初期サイズ | 1280 × 860 | UI-011 |
| ウィンドウ最小サイズ | 640 × 480 | UI-011 |
| ツールバー高さ | 40 | UI-023 |
| ステータス領域高さ | 24 | UI-060 |
| ファイルツリーペイン幅（既定 / 最小 / 最大） | 260 / 160 / ウィンドウ幅の 40 % | UI-030 |
| アウトラインペイン幅（既定 / 最小 / 最大） | 240 / 160 / ウィンドウ幅の 40 % | UI-040 |
| リサイザの幅（見た目 / 当たり判定） | 1 / 8 | — |
| 本文の最大幅 | 980 | UI-050 |

### DSP-031: 間隔の基準 **SHOULD**

余白は 4 px を基準単位とし、`4 / 8 / 12 / 16 / 24 / 32` から選ぶ。中間値を使わない。

### DSP-032: ツールバー内の寸法 **MUST**

| 対象 | 値 |
| --- | --- |
| ボタンのクリック領域 | 28 × 28 |
| ボタン間の間隔 | 4 |
| ツールバー左右のパディング | 8 |
| ファイル・再読み込み・テーマの群と、トグル 2 つの群の間隔 | 12 |

「?」ボタンは右端に寄せ、他のボタンとの間に伸縮する余白（`flex: 1`）を置く（UI-020）。

## 20.5 装飾（DSP-040 系）

### DSP-040: 角丸・境界・影 **MUST**

| 対象 | 値 |
| --- | --- |
| ボタン・入力欄の角丸 | 6px |
| コードブロック・Alerts の角丸 | 6px |
| ダイアログの角丸 | 12px |
| ペイン境界 | `1px solid var(--border-default)` |
| ダイアログの影 | `var(--shadow-overlay)` |
| ボタンのホバー背景 | `var(--neutral-muted)` |

影はダイアログとドロップオーバーレイにのみ用いる。ペインやツールバーに影を落とさない。

### DSP-041: スクロールバー **SHOULD**

- テーマに追従させる（FR-070）。`scrollbar-color: var(--fg-subtle) transparent` を指定する。
- 幅は OS の既定に従う。細くしすぎない。
- 本文・ペイン・ダイアログのいずれもスクロールバーの領域を確保し、スクロールの有無でレイアウトが横に揺れないよう `scrollbar-gutter: stable` を指定する。

## 20.6 モーション（DSP-050 系）

### DSP-050: アニメーションの方針 **MUST**

「動作が軽い」ことを優先し、装飾的なアニメーションを持たない（01-overview 1.3.2）。

| 対象 | 扱い |
| --- | --- |
| テーマ切り替え | トランジションなし（DSP-011） |
| ペインの開閉 | トランジションなし。即座に切り替える |
| ボタンのホバー | 背景色のみ 80 ms のフェード |
| コピー成功の表示 | アイコンの差し替えのみ。1.5 秒後に戻す |
| ダイアログの表示 | 100 ms のフェードイン |
| ドロップオーバーレイ | 80 ms のフェードイン |
| スクロール（アンカー移動） | 即座に移動する。スムーススクロールを使わない（FR-041） |

### DSP-051: 動きの抑制 **SHOULD**

`@media (prefers-reduced-motion: reduce)` の環境では、上記のフェードもすべて無効にする。
