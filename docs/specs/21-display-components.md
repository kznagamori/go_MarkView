## 21.1 ツールバー（DSP-100 系）

### DSP-100: 外観 **MUST**

UI-020 を実装する（4.75.0 で並びと区切りを改めた）。

```
┌────────────────────────────────────────────────────────────────────────────────┐
│ 8px                                                                        8px │
│ ┌──┐ ┌──┐ | ┌──┐ ┌──┐ | ┌──┐ ┌──┐ ┌──┐ | ┌──┐ ┌──┐ | ┌──┐ ┌──┐   flex:1   ┌──┐ │ 40px
│ │< │ │> │ | │O │ │R │ | │F │ │L │ │T │ | │E │ │M │ | │S │ │A │            │? │ │
│ └──┘ └──┘ | └──┘ └──┘ | └──┘ └──┘ └──┘ | └──┘ └──┘ | └──┘ └──┘            └──┘ │
└────────────────────────────────────────────────────────────────────────────────┘
  28×28  4px 間隔  | = 区切り線（DSP-103）。S と A（修飾の群）は、手前の区切りと一緒に編集モードの間だけ出す
  < = 戻る  > = 進む  O = 開く  R = 再読み込み  F = ファイルツリー  L = アウトライン  T = テーマ
  E = エディタで開く  M = 編集モード  S = 取り消し線  A = 文字色  ? = アプリケーション情報（アイコンは IMP-203）
```

- **群は左から、移動（戻る・進む）・ファイル（開く・再読み込み）・表示（ファイルツリー・アウトライン・テーマ）・編集（エディタで開く・編集モード）・修飾（取り消し線・文字色）の順とする**（UI-020）。**ファイルツリーのボタンをアウトラインのボタンの左に置く**（画面のペインの並びとそろえる。v1.1.0 までは逆だった）。
- **編集モードのボタン（`#btn-editmode`）はトグル**であり、ON の表現は DSP-101 のトグル ON に従う。**エディタで開くボタン（`#btn-edit`）の右に置く**（UI-020 の左 9）。アイコンは `icon-editmode`（IMP-203）。
- **エディタで開くボタンのアイコンは `icon-external`（四角から矢印が出る形）とする**（4.75.0。IMP-203）。鉛筆はコードブロックと図の編集のボタン（DSP-124）に譲った。
- **修飾の群のボタン（`#btn-strike` / `#btn-color`）は、ほかのボタンと同じ見た目とする**（DSP-101）。文字色のボタンは押すと一覧（DSP-141）を出し、開いている間はトグル ON と同じ見た目にする（`aria-expanded="true"`）。

| 項目 | 値 |
| --- | --- |
| 背景 | `--canvas-subtle` |
| 下境界 | `1px solid var(--border-default)` |
| 高さ | 40px（DSP-030） |
| アイコン色 | DSP-014 に従う |

### DSP-101: ボタンの状態表現 **MUST**

UI-021 を実装する。

| 状態 | 背景 | アイコン色 | 備考 |
| --- | --- | --- | --- |
| 通常 | 透明 | `--fg-muted` | |
| ホバー | `--neutral-muted` | `--fg-default` | 80 ms フェード（DSP-050） |
| 押下中 | `--neutral-muted-strong` | `--fg-default` | `--neutral-muted` の 1.5 倍の濃さ |
| フォーカス | 透明 | `--fg-default` | フォーカスリング（DSP-016） |
| トグル ON | `--accent-subtle` | `--accent-fg` | `aria-pressed="true"` |
| 無効 | 透明 | `--fg-subtle` | `cursor: default`、ホバー効果なし |

- **戻る・進むのボタンは、戻れない・進めないときに「無効」で描く**（UI-021。4.75.0）。**再読み込みのボタンは、文書未表示（`welcome`）で「無効」**、**エディタで開くボタンは、文書未表示と画像ファイルで「無効」**、**修飾の群のボタンは、使えないとき（選択が空、修飾できる 1 つのブロックに収まっていない）に「無効」**で描く（UI-021）。
- **文字色のボタンが一覧を開いている間（`aria-expanded="true"`）と、ファイルツリーのフィルターボタンが枚を開いている間は、「トグル ON」と同じ見た目にする**（DSP-115, DSP-141）。

### DSP-102: ツールチップ **MUST**

UI-024 を実装する。

| 項目 | 値 |
| --- | --- |
| 表示位置 | ボタンの下、6px の間隔 |
| 表示遅延 | 400 ms |
| 背景 / 文字 | `--fg-default` / `--canvas-default`（反転） |
| 角丸 / パディング | 6px / 4px 8px |
| フォントサイズ | 12px |
| 折り返し | しない。1 行で表示する |

文言は `Open / 開く (Ctrl+O)` 形式（UI-024）。英日併記のため通常のツールチップより横幅が広くなるが、折り返さず 1 行に収める。

- **本文中のボタン（図と画像・コードブロックの編集 DSP-124、並べ替え DSP-125）と拡大画面の操作バー（DSP-173）にも、同じ見た目のツールチップを出す**（UI-053, UI-054, UI-104）。文言は英語だけとする（UI-024）。
- **ファイルツリーペインの見出しのボタン（フィルターボタン）とフィルターの選択肢（DSP-115）にも、同じ見た目のツールチップを出す**（4.75.0）。文言は英日併記とする（UI-024。`Filter / フィルター (Markdown, Diagrams)`）。
- **表示位置はボタンの下を基本とし、ウィンドウの下端から出る場合はボタンの上に、同じ 6px の間隔で出す。** 左右は、ウィンドウの内側に収まるよう寄せる（IMP-247）。

### DSP-103: 区切り線と修飾の群 **MUST**

UI-020 / UI-021 を実装する（4.75.0）。フックは `.tb-sep` と `#tb-format`（IMP-202）。

| 項目 | 値 |
| --- | --- |
| 区切り線の大きさ | 幅 1px・高さ 20px。ツールバーの高さ（40px）の中で上下中央 |
| 区切り線の色 | `--border-default`（ツールバーの下境界と同じ。DSP-100） |
| 区切り線の左右 | `margin: 0 4px`。ボタン間の `gap`（4px。DSP-032）と合わせて、**ボタン → 区切り → ボタンが 8 + 1 + 8** |
| 操作 | 押せない。`Tab` の移動先にならない（`aria-hidden="true"`。UI-020） |
| 修飾の群（`#tb-format`） | 手前の区切り線と 2 つのボタンを包む。`display: contents` か `inline-flex` とし、**群の中の間隔を他の群と同じにする**。出し入れは `hidden`（IMP-202） |

- **区切り線の間隔は DSP-031 の値で組む**（4 の倍数）。
- **区切り線に影や凹凸を付けない。** 群の境目を示すだけの線である（UI-020）。

## 21.2 サイドペイン（DSP-110 系）

### DSP-110: ペイン共通 **MUST**

| 項目 | 値 |
| --- | --- |
| 背景 | `--canvas-subtle` |
| 右境界 | `1px solid var(--border-default)` |
| 縦スクロール | 内容が溢れる場合のみ表示 |
| 横スクロール | 許可する（UI-030。ファイル名を省略しないため） |
| スクロールする器 | **アウトライン**はペイン（`.pane`）そのもの。**ファイルツリーは `.pane-body` だけ**とし、見出しの行（`.pane-head`）とツリールートの名前の行（`#tree-root-name`）はその外に置く（4.75.0。UI-030） |

- **ファイルツリーのペインは、縦に並べた 3 つ（見出しの行・ツリールートの名前の行・`.pane-body`）の flex の列とし、`.pane-body` が残りの高さを取ってスクロールする**（IMP-202）。**横にスクロールしても、見出しの行の右端のボタンとツリールートの名前は動かない**（UI-030）。v1.1.0 は見出しの行が `position: sticky; top: 0` で縦にしか留まらず、横にスクロールすると一緒に流れた。

### DSP-111: ペイン見出し **MUST**

`Files` / `Outline` の見出しは、ペイン上部に固定表示する（スクロールで流れない）。**ファイルツリーの見出しの行は、右端にペインの機能のボタン（`.pane-actions`）を右から左へ並べる**（UI-030。4.75.0。v1.2.0 はフィルターボタンだけ。寸法は DSP-115）。

| 項目 | 値 |
| --- | --- |
| 文字 | 11px、大文字、字間 0.04em、`--fg-muted` |
| 高さ | 28px |
| パディング | 0 12px（**ファイルツリーは `0 4px 0 12px`**——右端のボタンを端に寄せる。4.75.0）。**高さ・パディング・背景は、ファイルツリーでは見出しの行（`.pane-head`）、アウトラインでは `.pane-title` に与え、`.pane-head` の中の `.pane-title` は余白を持たない**（IMP-202。二重に取らない。4.76.0） |
| 背景 | `--canvas-subtle`（スクロール時も透過させない） |
| 下境界 | なし |
| 見出しの文字とボタン（ファイルツリー） | 見出しの文字は左、`.pane-actions` は右（`margin-left: auto`）。**ペインの最小幅（160px。UI-030）でも、ボタン 3 つまでは見出しの文字と重ならない**（左の余白 12・`FILES` 約 40・ボタン 24 × 3 と間隔 4 × 2・右の余白 4）。4 つ目を足すときは、見出しの文字を省略表示にするかを決める |

### DSP-112: ファイルツリー **MUST**

UI-030 を実装する。

```
┌────────────────────────┐
│ FILES              [Y] │ ← 28px、11px 大文字。[Y] はフィルターボタン（DSP-115）
│ go_MarkView            │ ← ツリールート名、12px、--fg-muted。長ければ末尾を省略
├────────────────────────┤
│ ▾ 📁 docs              │ ← 行高 24px
│   ▾ 📁 specs           │
│       📄 README.md     │ ← 選択中: --accent-subtle
│       📄 01-overview.md│
│     📄 README.md       │
└────────────────────────┘
   ↑ 1 レベル 12px インデント
```

| 項目 | 値 |
| --- | --- |
| 行の高さ | 24px |
| インデント | 1 レベルあたり 12px |
| アイコンと名前の間隔 | 6px |
| 展開矢印 | 12 × 12px、`--fg-muted`。閉: `#icon-chevron-right` / 開: `#icon-chevron-down` |
| ディレクトリのアイコン | 閉: `#icon-dir` / 開: `#icon-filetree` |
| ファイルのアイコン | **種類ごとに分ける**（UI-030。4.75.0）: Markdown は `#icon-file`、図（PlantUML・Mermaid）は `#icon-diagram`、画像は `#icon-image`。種類は `TreeNodeDTO.kind`（IMP-304） |
| ツリールートの名前の行 | 1 行。**収まらなければ末尾を省略する**（`text-overflow: ellipsis`。4.75.0）。ツリーの横スクロールでは動かない（DSP-110）。絶対パスはツールチップ（`title`。UI-030） |
| 通常の文字 | 13px、`--fg-default` |
| ホバー | 背景 `--neutral-muted` |
| 選択中 | 背景 `--accent-subtle`、文字 `--fg-default`、左端に 2px の `--accent-fg` |
| 切り詰め表示（FR-032） | 末尾に `… and N more` を `--fg-subtle` で表示。クリック不可 |

ツリールートの外を表示している場合、選択中の行は存在しない（FR-052, DSP-330）。**表示中のファイルの種類をフィルターで隠している場合も同じ**（FR-031。4.75.0）。

### DSP-113: アウトライン **MUST**

```

├────────────────────────┤
│ MarkView               │ ← h1: 13px
│   Overview             │ ← h2: 13px, 12px インデント

│     Scope              │

| 項目 | 値 |
| --- | --- |
| 行の高さ | 24px |
| インデント | 1 レベルあたり 12px（UI-040） |
| 文字サイズ | h1〜h3: 13px、h4 以降: 12px |
| 通常の文字 | `--fg-muted` |
| ホバー | 文字 `--fg-default`、背景 `--neutral-muted` |

### DSP-115: ペインの見出しのボタンとフィルターの枚 **MUST**

UI-030 / UI-033 / IMP-271 を実装する（4.75.0）。フックは `.pane-actions` の `.pane-btn`（`#btn-treefilter`）と `#treefilter`、その中の `.treefilter-head` / `.treefilter-title` / `.treefilter-close` / `label.treefilter-option`（IMP-202, IMP-271）。

```
ペインの見出しの行（閉じているとき）      ボタンで開く枚（ボタンの下に重ねる）

+--------------------------+            +------------------------------+
| FILES                [Y] |            | Show in tree             (X) |
| go_MarkView              |            | [x] Markdown (.md/.markdown/ |
|--------------------------|            |     .mdown/.mkd)             |
| v docs                   |            | [x] Diagrams (.puml/.pu/.wsd/|
|     README.md            |            |     .plantuml/.mmd/.mermaid) |
|     arch.puml            |            | [ ] Images (.png/.jpg/.jpeg/ |
|   README.md              |            |     .gif/.svg/.webp/.avif/   |
+--------------------------+            |     .bmp/.ico)               |
                                        +------------------------------+
  [Y] = フィルターボタン（icon-filter）  (X) = 閉じるボタン（icon-close）
  Markdown の [x] は常にチェック済みで押せない。枚はペインより広ければアウトラインや本文の上へはみ出す
```

**ボタン**（`.pane-btn`）

| 項目 | 値 |
| --- | --- |
| 大きさ | 24 × 24px、アイコン 16px（検索バーのボタンと同じ。DSP-160） |
| 間隔 | 4px（右から左へ並べる） |
| 状態 | DSP-101 と同じ（通常・ホバー・押下中・フォーカス）。**枚を開いている間（`aria-expanded="true"`）はトグル ON の見た目**。**閉じている間の見た目は、表示している種類で変えない**（UI-033。状態はツールチップで示す） |
| ツールチップ | DSP-102。`Filter / フィルター (<表示している種類>)`（UI-024） |

**枚**（`#treefilter`）

| 項目 | 値 |
| --- | --- |
| 幅 | **320px**（利用者の判断）。ウィンドウ幅が 320 + 16px より狭いときは、ウィンドウ幅 − 16px |
| 位置 | **ボタンの下 4px。枚の右端をボタンの右端にそろえる。** 左端がウィンドウの左端から 8px より左へ出るなら、左端を 8px に寄せる（その分、ペインの右へはみ出す）。ツリーと一緒にスクロールしない（IMP-271） |
| 背景・枠・角丸・影 | `--canvas-overlay`、`1px solid var(--border-default)`、6px、`--shadow-overlay`（検索バーと同じ。DSP-160） |
| パディング | 8px 12px |
| 見出し | `Show in tree`。13px、太字、`--fg-default`。行の高さ 24px。右端に閉じるボタン（24 × 24px、`icon-close` 16px） |
| 選択肢 | 1 つずつ行に並べる。行の間 4px。チェックボックスと文言の間 6px。文言は 13px、`--fg-default`。**括弧の中の拡張子は、枚の幅で折り返す**（`/` の後ろで折り返してよい。`overflow-wrap: anywhere`）。折り返した行は文言の頭にそろえる |
| Markdown の選択肢 | チェックボックスは `disabled`（エンジンの既定の淡色）。**文言は `--fg-muted` とし、読める濃さを保つ**（UI-033。`--fg-subtle` にしない） |
| フォーカス | チェックボックスとボタンにフォーカスリング（DSP-016） |
| 重なり順 | `z-index: 50`（DSP-015。状態画面より上、ダイアログより下） |
| 表示 / 消去 | **トランジションなし**（DSP-050。検索バーと同じ） |

- **枚が開いている間は、ツリーの上部を隠す**（外をクリックしても閉じないため。UI-033）。
- **チェックボックスの見た目はエンジンの既定に委ね、`accent-color` を `--accent-emphasis` にする**（本文のタスクリストと同じ。DSP-121, BUG-018）。

| **描画しないとき** | コードブロック表示のまま、上部に理由を `--danger-fg`、12px で併記（DSP-270 と同じ）。理由は 3 種（下表） |

> [!IMPORTANT]
> **「エラー図をそのまま出す」と「理由を併記する」は別の状態である。** 前者は PlantUML 自身が行番号付きで描いた**図が出ている**状態、後者は MarkView が描画をやめて**図が出ていない**状態である。見た目を混ぜない。
>
> Mermaid（DSP-270）は構文エラーでも後者の形になる。**同じ「構文エラー」で見た目が違うのは、処理系の返し方が違うからである**（FR-024）。

理由は次の 3 種とする。文言は `strings.js`（IMP-290）に持つ。

| 理由 | 起きる場面 | 文言のキー |
| --- | --- | --- |
| 取り込み指令を含む | Go 側が `data-puml-error="include"` を付けた（IMP-119） | `pumlInclude` |
| 処理系が図を返さなかった | 4096 px 超え、未対応の図種別（`ditaa` 等。MD-083） | `pumlUnsupported` |
| 描画が完了しなかった | 資産の読み込み失敗、タイムアウト（IMP-233） | `pumlFailed` |

> [!IMPORTANT]
> **判定は「SVG が得られたか」だけで行う。** 図種別ごとの判定をフロントエンドに持たない（IMP-233）。
>
> このため、**処理系がエラー図（SVG）を返す種別は「図が出ている」側に入る。** `salt` のように版によってエラー図を返したり例外テキストを返したりするものは、どちらの見え方にもなりうる。**どちらであっても空白にならず、他の図の描画を止めない**ことが要件である。

### DSP-273: 図のファイル **MUST**

- **画像を拡大すると輪郭がぼやけてよい**（FR-122）。`image-rendering` は既定のままとし、ピクセルを角張らせない。

**代わりの要素**（`.expand-placeholder`）

| 項目 | 値 |
| --- | --- |
| 大きさ | `width: var(--placeholder-width)`、`height: var(--placeholder-height)`（移す前の図・画像の大きさ。IMP-253） |
| 見た目 | 何も描かない（拡大画面が本文を覆っているため見えない） |
| 表示と縦の揃え | `display: inline-block`。**`vertical-align` は既定の `baseline` のまま**とする。図（インラインの `svg`）と画像（`img`）は下端をベースラインに揃え、行の下に余白を持つ。`top` にすると、その余白の分だけ本文が縮み、スクロール位置が動く（Mermaid の図で 5.7px。FR-122 の「本文のスクロール位置を保つ」） |

## 21.12 右クリックメニュー（DSP-140 系）

### DSP-140: 外観 **MUST**

UI-085 / UI-032 / FR-063 / FR-036 / IMP-249 / IMP-270 を実装する。フックは `#contextmenu`、項目は `.contextmenu-item`、区切りは `.contextmenu-separator`（IMP-249）。**ファイルツリーのメニュー（UI-032。4.75.0）も同じ見た目とする**（項目だけが違う）。

```
┌──────────────────────┐
│ Copy link address    │  <- 項目 28px
├──────────────────────┤  <- 区切り 1px（上下 4px）
│ Copy                 │
│ Select all           │
└──────────────────────┘
  最小幅 180px、上下パディング 4px
```

| 項目 | 値 |
| --- | --- |
| 背景 | `--canvas-overlay` |
| 枠・角丸・影 | `1px solid var(--border-default)`、6px、`--shadow-overlay` |
| 幅 | 最小 180px。項目の文言に合わせて広がる（項目は `white-space: nowrap` で折り返さない。**これにより、ウィンドウの右端の近くに置いても幅が縮まない**） |
| パディング | 上下 4px |
| 項目 | 高さ 28px、`padding: 0 12px`、13px、`--fg-default`、左寄せ |
| ホバー / キーボードで選んだ項目 | 背景 `--neutral-muted`。**`:hover`（使えない項目を除く）と `:focus-visible` で塗り、`:focus` では塗らない**——マウスで開いたときも最初の使える項目へフォーカスを移す（IMP-249）ため、`:focus` で塗ると選んでいない項目が選ばれて見える |
| フォーカス | 選んでいる項目の背景（上）に加え、フォーカスリング（DSP-016） |
| 使えない項目（`.contextmenu-item:disabled`） | 文字 `--fg-subtle`、`cursor: default`、ホバー効果なし（DSP-101 の「無効」と揃える） |

### DSP-141: サブメニューと文字色の一覧 **MUST**

UI-085 / UI-020 / FR-146 / FR-147 / IMP-249 / IMP-265 を実装する（4.75.0）。フックは `#contextsubmenu`（右クリックメニューの `Text color` のサブメニュー）と、`#contextmenu.is-color-list`（ツールバーから開いた文字色の一覧。`#contextmenu` を使い回すため、幅を分けるクラスを IMP-249 が付け外しする。4.76.0）。**どちらも DSP-140 と同じ枠・項目・区切りの見た目とし、違うところだけをここに定める**（UI-085 の「同じ見た目と操作」）。

```
本文ペイン（編集モード）          Text color のサブメニュー

┌──────────────────────┐          ┌────────────────┐
│ [v] Strikethrough    │          │ [v] [#] Red    │ <- 選択の全体がこの色なら印
│     Text color     > │ -------> │     [#] Orange │
├──────────────────────┤          │     [#] Yellow │
│     Copy             │          │     [#] Green  │
│     Select all       │          │     [#] Blue   │
└──────────────────────┘          │     [#] Purple │
                                  │     [#] Gray   │
                                  ├────────────────┤
                                  │         Default│
                                  └────────────────┘
  [v] = 印（icon-check 16px）  [#] = 色の見本（12px の四角）  > = サブメニューの矢印
```

| 項目 | 値 |
| --- | --- |
| 印の列 | 項目の左に 16px の列を取り、印（`icon-check`、`--fg-default`）を置く。**印の無い項目も同じ列を空けて、文字の頭をそろえる**（修飾の項目を含むメニューだけ。`.contextmenu:has([role=menuitemcheckbox], [role=menuitemradio])` で選ぶ。含まないメニューは v1.1.0 のまま列を取らない） |
| サブメニューの矢印 | `Text color` の項目の右端に `icon-chevron-right`（12px、`--fg-muted`） |
| 色の見本（`span.color-swatch.md-color-<名前>`。IMP-249） | 12 × 12px の四角、角丸 2px。**塗りはいまのテーマで描く色**（DSP-010）。**本文の外にあるため、DSP-121 の文字色の規則に頼らず、`components.css` で `.color-swatch.md-color-<名前> { background-color: var(--md-color-<名前>) }` を書く。** 枠 `1px solid var(--border-muted)`。見本と名前の間 8px |
| `Default` | 見本を出さない（見本の列は空け、文字の頭を色の名前にそろえる）。一覧の最後に区切りを挟んで置く |
| サブメニューの位置 | `Text color` の項目の右に、上端をその項目の上端にそろえて出す（本メニューとの間 2px）。**ウィンドウの右端で収まらなければ、本メニューの左に出す。** 下端で収まらなければ上へずらす（ウィンドウの端から 8px 内側） |
| 文字色の一覧の位置（ツールバー） | **文字色のボタンの下 4px、左端をボタンの左端にそろえる**（右端で収まらなければ右端をそろえる） |
| 幅 | 最小 140px（文言に合わせて広がる） |
| 重なり順 | `z-index: 70`（右クリックメニューと同じ。DSP-015） |
| 表示 / 消去 | トランジションなし（DSP-050） |

- **修飾の項目が淡色のとき**（選択が空など。IMP-265）、`Text color` のサブメニューは開かない。
- **印の意味**: `Strikethrough` は選択の全体が取り消し線、色は選択の全体がその色（UI-085）。色が混ざっているときは、どの色にも印を付けない。
