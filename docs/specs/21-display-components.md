## 21.1 ツールバー（DSP-100 系）

### DSP-100: 外観 **MUST**

UI-020 を実装する。

```
┌───────────────────────────────────────────────────────────────┐
│ 8px                                                       8px │
│ ┌──┐ ┌──┐ ┌──┐  12px  ┌──┐ ┌──┐              flex:1  ┌──┐ │ 40px
│ │📁│ │⟳ │ │◐ │        │☰ │ │🗂│                      │? │ │
│ └──┘ └──┘ └──┘        └──┘ └──┘                      └──┘ │
└───────────────────────────────────────────────────────────────┘
  28×28  4px 間隔                 トグル 2 つ            右端
```

| 項目 | 値 |
| --- | --- |
| 背景 | `--canvas-subtle` |
| 下境界 | `1px solid var(--border-default)` |
| 高さ | 40px（DSP-030） |
| アイコン色 | DSP-014 に従う |

### DSP-101: ボタンの状態表現 **MUST**

UI-021 を実装する。

| 状態 | 背景 | アイコン色 | 備考 |
| --- | --- | --- | --- |
| 通常 | 透明 | `--fg-muted` | |
| ホバー | `--neutral-muted` | `--fg-default` | 80 ms フェード（DSP-050） |
| 押下中 | `--neutral-muted-strong` | `--fg-default` | `--neutral-muted` の 1.5 倍の濃さ |
| フォーカス | 透明 | `--fg-default` | フォーカスリング（DSP-016） |
| トグル ON | `--accent-subtle` | `--accent-fg` | `aria-pressed="true"` |
| 無効 | 透明 | `--fg-subtle` | `cursor: default`、ホバー効果なし |

### DSP-102: ツールチップ **MUST**

UI-024 を実装する。

| 項目 | 値 |
| --- | --- |
| 表示位置 | ボタンの下、6px の間隔 |
| 表示遅延 | 400 ms |
| 背景 / 文字 | `--fg-default` / `--canvas-default`（反転） |
| 角丸 / パディング | 6px / 4px 8px |
| フォントサイズ | 12px |
| 折り返し | しない。1 行で表示する |

文言は `Open / 開く (Ctrl+O)` 形式（UI-024）。英日併記のため通常のツールチップより横幅が広くなるが、折り返さず 1 行に収める。

### DSP-110: ペイン共通 **MUST**

### DSP-111: ペイン見出し **MUST**

| 項目 | 値 |
| --- | --- |
| 文字 | 11px、大文字、字間 0.04em、`--fg-muted` |
| 高さ | 28px |
| パディング | 0 12px |
| 背景 | `--canvas-subtle`（スクロール時も透過させない） |
| 下境界 | なし |

### DSP-112: ファイルツリー **MUST**

UI-030 を実装する。

```
┌────────────────────────┐
│ FILES                  │ ← 28px、11px 大文字
│ go_MarkView            │ ← ツリールート名、12px、--fg-muted
├────────────────────────┤
│ ▾ 📁 docs              │ ← 行高 24px
│   ▾ 📁 specs           │
│       📄 README.md     │ ← 選択中: --accent-subtle
│       📄 01-overview.md│
│     📄 README.md       │
└────────────────────────┘
   ↑ 1 レベル 12px インデント
```

| 項目 | 値 |
| --- | --- |
| 行の高さ | 24px |
| インデント | 1 レベルあたり 12px |
| アイコンと名前の間隔 | 6px |
| 展開矢印 | 12 × 12px、`--fg-muted`。閉: `#icon-chevron-right` / 開: `#icon-chevron-down` |
| ディレクトリのアイコン | 閉: `#icon-dir` / 開: `#icon-filetree` |
| ファイルのアイコン | `#icon-file` |
| 通常の文字 | 13px、`--fg-default` |
| ホバー | 背景 `--neutral-muted` |
| 選択中 | 背景 `--accent-subtle`、文字 `--fg-default`、左端に 2px の `--accent-fg` |
| 切り詰め表示（FR-032） | 末尾に `… and N more` を `--fg-subtle` で表示。クリック不可 |

ツリールートの外を表示している場合、選択中の行は存在しない（FR-052, DSP-330）。

### DSP-113: アウトライン **MUST**

UI-040 を実装する。

```
┌────────────────────────┐
│ OUTLINE                │
├────────────────────────┤
│ MarkView               │ ← h1: 13px
│   Overview             │ ← h2: 13px, 12px インデント
│     Purpose            │ ← h3: 12px, 24px インデント
│     Scope              │
│   Usage                │ ← 現在位置: 強調
└────────────────────────┘
```

| 項目 | 値 |
| --- | --- |
| 行の高さ | 24px |
| インデント | 1 レベルあたり 12px（UI-040） |
| 文字サイズ | h1〜h3: 13px、h4 以降: 12px |
| 通常の文字 | `--fg-muted` |
| ホバー | 文字 `--fg-default`、背景 `--neutral-muted` |
| 現在位置（FR-042） | 文字 `--accent-fg`、左端に 2px の `--accent-fg`、背景 `--accent-subtle` |
| 長い見出し | 1 行で省略（`text-overflow: ellipsis`）。全文はツールチップ |
| 見出しなし | `No headings` を `--fg-subtle`、12px、中央寄せで表示 |

アウトラインは横スクロールさせず省略表示とする。ファイルツリー（横スクロール・省略なし）と扱いが逆なのは、ファイル名は完全一致で識別する必要があるのに対し、見出しは先頭部分で判別できるためである。

### DSP-114: リサイザ **MUST**

| 項目 | 値 |
| --- | --- |
| 見た目の幅 | 1px（`--border-default`） |
| 当たり判定の幅 | 8px（中央に見た目の線） |
| カーソル | `col-resize` |
| ホバー / ドラッグ中 | 線の色を `--accent-fg` に変える |

ドラッグ中はテキスト選択を抑止する（`user-select: none`）。

## 21.3 本文ペイン（DSP-120 系）

### DSP-120: 領域 **MUST**

UI-050 を実装する。

| 項目 | 値 |
| --- | --- |
| 背景 | `--canvas-default` |
| 最大幅 | 980px、超える場合は中央寄せ（DSP-030） |
| パディング | 上下 24px、左右 32px（ウィンドウが狭い場合は 16px まで縮小） |
| 縦スクロール | 常に領域を確保（DSP-041） |
| 横スクロール | 発生させない（UI-050） |

### DSP-121: 本文要素 **MUST**

MD-020〜MD-026 を実装する。値は `github-markdown-css` に従う（DSP-001）。代表値を以下に示す。

| 要素 | 主な指定 |
| --- | --- |
| 段落 | 下マージン 16px |
| リスト | 左パディング 2em、項目間 4px、入れ子は 16px の上下マージン |
| タスクリスト | チェックボックスは読み取り専用（MD-022）。`cursor: default`、`pointer-events: none` |
| 引用 | 左に 4px の `--border-default`、左パディング 16px、文字 `--fg-muted`。**本文と同じ左端から始める**（ブラウザ既定の左右マージン 40px を打ち消す） |
| 水平線 | 高さ 0.25em（倍率 100 % で 4px。`--border-default`）、上下マージン 24px。**脚注の区切りだけは 1px** |
| インラインコード | 背景 `--neutral-muted`、角丸 6px、パディング 0.2em 0.4em、サイズ 85 % |
| リンク | 色 `--accent-fg`、**常に下線**（`text-underline-offset: 0.2em`）。色だけで区別しない |
| 脚注 | 文書末尾に区切り線を挟んで一覧表示、12px。参照は `[1]` の形（括弧は CSS で付ける）、戻りリンクは `↩` |
| 生 HTML のインライン要素（MD-072） | `mark` は背景 `--attention-subtle`・文字 `--fg-default`（**ブラウザ既定の純黄色を使わない**）。`small` は 90 %。`abbr[title]` は点線の下線。`kbd` は等幅 11px 相当、地 `--canvas-subtle`、枠と内側の影 `--border-muted`、角丸 6px |

### DSP-122: 表 **MUST**

MD-024 を実装する。

| 項目 | 値 |
| --- | --- |
| 枠線 | セルごとに `1px solid var(--border-default)` |
| ヘッダ行 | 太字、背景 `--canvas-subtle` |
| 偶数行 | 背景 `--canvas-subtle` |
| セルのパディング | 6px 13px |
| 幅が溢れる場合 | **表の内部だけを横スクロール**させる（UI-050）。`table` 自身に `display: block` と `width: max-content` を与えて実現し、ラッパ要素を足さない。本文の DOM を変えないため、見出しアンカーの位置も検索の走査対象も変わらない |

### DSP-123: 画像 **MUST**

FR-022 を実装する。

| 項目 | 値 |
| --- | --- |
| 最大幅 | 100 %（本文幅）。縦横比を維持して縮小 |
| 背景 | `--canvas-default`（透過 PNG の視認性のため） |
| 読み込み失敗時 | 破線 1px の枠（`--border-default`）内に alt テキストを `--fg-muted` で表示。高さは内容に応じる |

## 21.6 Mermaid と数式（DSP-270 系）

### DSP-270: Mermaid 図 **MUST**

MD-080 を実装する。

| 項目 | 値 |
| --- | --- |
| 配置 | 本文幅の中央 |
| 最大幅 | 100 %。超える場合は縦横比を保って縮小 |
| 背景 | `--canvas-default` |
| 上下マージン | 16px |
| Mermaid テーマ | Light: `default` / Dark: `dark`（IMP-231） |

MD-060 を実装する。

| 項目 | 値 |
| --- | --- |
| インライン数式 | 本文と同じ行に配置。前後に余白を入れない |
| ブロック数式 | 中央寄せ、上下マージン 16px、横に溢れる場合はその要素内で横スクロール |
| 文字色 | `--fg-default`（KaTeX の既定色を上書きし、テーマに追従させる） |

## 21.7 ステータス領域（DSP-150 系）

### DSP-150: 外観 **MUST**

UI-060 を実装する。

```
┌──────────────────────────────────────────────────────────────┐
│ docs/specs/README.md              UTF-8  120 lines  140%     │ 24px
└──────────────────────────────────────────────────────────────┘
  左: --fg-muted 12px            右: --fg-subtle 12px
```

| 項目 | 値 |
| --- | --- |
| 高さ | 24px |
| 背景 | `--canvas-subtle` |
| 上境界 | `1px solid var(--border-default)` |
| パディング | 0 12px |
| 左（パス） | 12px、`--fg-muted`。溢れたら**先頭**を省略（`…/specs/README.md`） |
| 右（メタ） | 12px、`--fg-subtle`。項目間は 12px |
| ツリー外表示 | 絶対パスの末尾に ` (outside tree)` を `--fg-subtle` で付す（FR-052） |

パスを先頭から省略するのは、末尾のファイル名が識別に最も重要なためである。

### DSP-151: 一時メッセージ **MUST**

FR-110 を実装する。

| 種別 | 背景 | 文字 | 表示時間 |
| --- | --- | --- | --- |
| 情報 | `--accent-subtle` | `--accent-fg` | 5 秒 |
| 警告 | `--attention-subtle` | `--attention-fg` | 5 秒 |
| エラー | `--danger-subtle` | `--danger-fg` | 5 秒 |

- ステータス領域の全幅を一時的に占有し、5 秒後に元の表示へ戻る（UI-060）。
- 表示中に新しいメッセージが来た場合、置き換えてタイマをリセットする。積み上げない。
- 溢れる場合は末尾を省略し、全文はツールチップで示す。
