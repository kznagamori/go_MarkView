### DSP-123: 画像 **MUST**

FR-022 を実装する。

| 項目 | 値 |
| --- | --- |
| 最大幅 | 100 %（本文幅）。縦横比を維持して縮小。**原寸表示中を除く**（DSP-124） |
| 背景 | `--canvas-default`（透過 PNG の視認性のため） |
| 読み込み失敗時 | 破線 1px の枠（`--border-default`）内に alt テキストを `--fg-muted` で表示。高さは内容に応じる |

読み込みに失敗した画像は、**`<img>` を `<span class="img-broken">` へ置き換えて描く**（IMP-226）。**代替テキストは自前で描く。**

| 項目 | 値 |
| --- | --- |
| フック | **`span.img-broken`** |
| 中身 | `alt` の文字列。**`textContent` で入れる**（IMP-220） |
| `display` | `inline-block`（枠を成立させるため） |
| 枠 | `1px dashed var(--border-default)` |
| 文字色 | `--fg-muted` |
| 余白 | `padding: 8px 12px` |
| 背景 | なし（`transparent`）。成功時の地は失敗時には意味がない |

> [!IMPORTANT]
> **代替テキストの描画をブラウザ既定に委ねてはならない**（NFR-061）。
>
> **既定の描画はエンジンごとに違う。** Blink（WebView2）は `alt` の文字列をインラインで流し込むが、
> **WebKitGTK は自前の壊れ画像アイコンを描き、`alt` を描かない**
> （[BUG-008](../bugs/2026-09-06-bug-008-broken-image-alt-webkitgtk.md)）。
> **`FR-022`（MUST）は「代替テキストと破損を示すプレースホルダを表示する」と定めており、枠だけでは満たさない。**
>
> **4.32.0 より前はフックが `img.is-broken` であった。** 枠は両エンジンで出ていたため、
> **「枠が出ているか」だけを見ると気づけない。** 見るのは**枠の中身**である。

> [!NOTE]
> **CSS だけでは実装できない。** 読み込みに失敗した `img` を選ぶセレクタが**どちらのエンジンにも存在しない**ため、置き換えに JavaScript が要る（IMP-226）。表示仕様がクラス名を名指ししているのはこのためで、`.img-broken` は 12 章と 21 章の接続点である。
>
> **`::after { content: attr(alt) }` で描く案は採らない。** `<img>` は置換要素であり、擬似要素が描かれるかどうかがエンジンと状態に依存する。**エンジン既定に委ねるのと同じ誤りを、別の場所で繰り返すことになる。**

### DSP-124: 図と画像のボタンと原寸表示 **MUST**

UI-053 / FR-121 / IMP-228 を実装する。

```
図（.code-block の右上）                        画像（.media-image の右上）

┌──────────────────────────────────────┐        ┌───────────────────────────┐
│                     [1:1] [<>] [C]   │        │               [1:1] [<>]  │
│                          4px  4px 8px│        │                    4px 8px│
│                                      │        │                           │
│                                      │        │                           │
└──────────────────────────────────────┘        └───────────────────────────┘
  [1:1] = 原寸表示  [<>] = 拡大画面  [C] = コピー（DSP-251）。UI-053 の図と同じ記号
```

**ボタン**（`.media-btn`）

| 項目 | 値 |
| --- | --- |
| サイズ | 28 × 28px（アイコン 16px）。コピーボタン（DSP-251）と同じ |
| 背景・枠・角丸 | `--canvas-default`、`1px solid var(--border-default)`、6px（DSP-251 と同じ） |
| 既定の不透明度 | 0.5（**`display:none` にしない**。UI-053）。ホバー・フォーカス時は 1.0 |
| ホバー | 背景 `--neutral-muted` |
| 原寸表示中（`aria-pressed="true"`） | 背景 `--accent-subtle`、アイコン `--accent-fg`、**不透明度 1.0**（DSP-101 のトグル ON と同じ表し方） |
| フォーカス | フォーカスリング（DSP-016） |
| アイコン | 原寸表示 `icon-actual-size`、拡大画面 `icon-expand`（IMP-203） |
| ツールチップ | DSP-102。`Actual size` / `Expand` |
| 重なり順 | `z-index: 10`（DSP-015） |

**ボタンの並び**（`.media-actions`）

| 対象 | 位置 |
| --- | --- |
| 図 | `.code-block` の上 8px、**右 40px**（コピーボタンの 28px と間隔 4px の左）。右から「拡大画面」「原寸表示」の順に 4px 間隔 |
| 画像 | `.media-image` の上 8px、右 8px。右から「拡大画面」「原寸表示」の順に 4px 間隔 |

- 画像の `.media-image` は `display: inline-block`、`position: relative`、`max-width: 100%` とし、中の `.media-frame` は `display: block`、`max-width: 100%` とする。**包む前と画像の位置と大きさが変わらない**ようにする（段落の中の画像の流れを崩さない）。原寸表示では `.media-image` も `display: block` にする（横スクロールの器を本文幅いっぱいに取るため）。セレクタは `.media-image:has(> .media-frame.is-actual)` とする（既存の `.code-block:has(> .mermaid-rendered)` と同じ書き方。クラスを 2 か所に付けない）。
- **画像が小さく、ボタンが画像からはみ出す場合**は、ボタンを画像の外（右上の外側）へ出してよい。ボタンを出すのは縮小表示中の画像だけであり（FR-120）、本文幅いっぱいに近い大きさを持つため、通常は起こらない。

**原寸表示**（`.media-frame.is-actual`）

| 項目 | 値 |
| --- | --- |
| 枠 | `display: block`、`max-width: 100%`、**`overflow-x: auto`**（その枠の内側で横スクロール。UI-050） |
| 中の図・画像 | `max-width: none`、`width: var(--media-natural-width)`、`height: auto` |
| 配置 | 図は左寄せにする（中央寄せのままだと、はみ出した左側へスクロールできない） |
| 横スクロールバー | 本文と同じ（DSP-041）。**はみ出したときだけ出す**（上の `overflow-x: auto`）。**`scrollbar-gutter` で下端の領域を確保しようとしない**——このプロパティが確保するのは縦スクロールバーの領域だけである。原寸表示中であることは、ボタンのトグル ON（上の表）で示す |

- **原寸表示の図と画像は倍率に追随しない**（DSP-021）。
- ボタンの位置は枠の右上に留まり、横スクロールで流れない（**ボタンを、スクロールする `.media-frame` の外側の `.code-block` / `.media-image` に置くため**。IMP-228）。

| **描画しないとき** | コードブロック表示のまま、上部に理由を `--danger-fg`、12px で併記（DSP-270 と同じ）。理由は 3 種（下表） |
| コピーボタン | 描画後も表示し、対象は元の PlantUML ソース（FR-060, IMP-119） |

> [!IMPORTANT]
> **「エラー図をそのまま出す」と「理由を併記する」は別の状態である。** 前者は PlantUML 自身が行番号付きで描いた**図が出ている**状態、後者は MarkView が描画をやめて**図が出ていない**状態である。見た目を混ぜない。
>
> Mermaid（DSP-270）は構文エラーでも後者の形になる。**同じ「構文エラー」で見た目が違うのは、処理系の返し方が違うからである**（FR-024）。

理由は次の 3 種とする。文言は `strings.js`（IMP-290）に持つ。

| 理由 | 起きる場面 | 文言のキー |
| --- | --- | --- |
| 取り込み指令を含む | Go 側が `data-puml-error="include"` を付けた（IMP-119） | `pumlInclude` |
| 処理系が図を返さなかった | 4096 px 超え、未対応の図種別（`ditaa` 等。MD-083） | `pumlUnsupported` |
| 描画が完了しなかった | 資産の読み込み失敗、タイムアウト（IMP-233） | `pumlFailed` |

> [!IMPORTANT]
> **判定は「SVG が得られたか」だけで行う。** 図種別ごとの判定をフロントエンドに持たない（IMP-233）。
>
> このため、**処理系がエラー図（SVG）を返す種別は「図が出ている」側に入る。** `salt` のように版によってエラー図を返したり例外テキストを返したりするものは、どちらの見え方にもなりうる。**どちらであっても空白にならず、他の図の描画を止めない**ことが要件である。

### DSP-173: 拡大画面 **MUST**

UI-104 / FR-122 / IMP-253 を実装する。**ダイアログ（DSP-170）とは違い、暗幕の上に浮かぶ枠ではなく、ステータス領域を除く画面いっぱいの不透明な面**とする。

| 領域 | 値 |
| --- | --- |
| 範囲 | `position: fixed`、上 0・左 0・右 0・**下 24px**（ステータス領域の高さ。DSP-030）。**ステータス領域を覆わない**（UI-104） |
| 背景 | `--canvas-default`（不透明） |
| 重なり順 | `z-index: 50`（DSP-015） |
| 表示 | 100 ms のフェードイン、閉じるときは即座に消す（DSP-050） |

**操作バー**（`.expand-bar`）

| 項目 | 値 |
| --- | --- |
| 高さ・背景・下境界 | 40px、`--canvas-subtle`、`1px solid var(--border-default)`（ツールバー DSP-100 と同じ） |
| パディング | `0 8px` |
| `Fit` / `1:1`（`.expand-fit` / `.expand-actual`） | 文字のボタン。高さ 28px、`padding: 0 8px`、13px、DSP-101 の状態表現（背景透明、ホバーで `--neutral-muted`） |
| `-` / `+`（`.expand-zoom-out` / `.expand-zoom-in`） | アイコンのボタン 28 × 28px（`icon-zoom-out` / `icon-zoom-in`。DSP-101） |
| 倍率の表示（`.expand-zoom-value`） | 12px、`--fg-muted`、幅 48px の中央寄せ、`font-variant-numeric: tabular-nums`（桁で揺れない） |
| 閉じる（`.expand-close`） | 右端。28 × 28px、`icon-close`（DSP-101） |
| ボタンの間隔 | 4px。`1:1` と `-` の間は 12px（DSP-032 の群の間隔と同じ） |
| 範囲の端 | 10 % で `-`、1000 % で `+` を DSP-101 の「無効」の見た目にする（**`[aria-disabled="true"]` で選ぶ。`disabled` 属性は付けない**——付けるとフォーカス中のボタンからフォーカスが外れる。IMP-253） |
| ツールチップ | DSP-102。`Fit (F)` / `Actual size (0)` / `Zoom out (-)` / `Zoom in (+)` / `Close (Esc)` |

**舞台**（`.expand-stage`）と中身（`.expand-content`）

| 項目 | 値 |
| --- | --- |
| 舞台 | 操作バーの下の残り全体。`overflow: hidden`、`position: relative`、`user-select: none` |
| カーソル | 通常 `grab`、ドラッグ中 `grabbing` |
| 中身の大きさ | `width: var(--expand-width)`、`height: var(--expand-height)`（本来の大きさ × 倍率。IMP-253） |
| 中身の位置 | `transform: translate(var(--expand-x), var(--expand-y))`（IMP-253）。**`scale()` を使わない、`will-change` を付けない**（IMP-253） |
| 中の図・画像 | `width: 100%`、`height: 100%`、`max-width: none` |
| 図の地 | `--canvas-default`。図の配色は本文と同じテーマのまま（UI-104） |
| 画像の地 | `--canvas-default`（透過画像の視認性。DSP-123 と同じ） |
| 中身の枠 | `1px solid var(--border-muted)`。**地と同じ色の図の端が分かるようにする** |

- **拡大・縮小・移動にトランジションを掛けない**（DSP-050）。
- **画像を拡大すると輪郭がぼやけてよい**（FR-122）。`image-rendering` は既定のままとし、ピクセルを角張らせない。

**代わりの要素**（`.expand-placeholder`）

| 項目 | 値 |
| --- | --- |
| 大きさ | `width: var(--placeholder-width)`、`height: var(--placeholder-height)`（移す前の図・画像の大きさ。IMP-253） |
| 見た目 | 何も描かない（拡大画面が本文を覆っているため見えない） |
