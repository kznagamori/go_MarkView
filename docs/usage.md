# 使い方

MarkView は Markdown を**読むための**アプリケーションです。文書を自由に書き換える機能はありません。
例外として、編集モードの間だけ、タスクリストのチェックボックス・表のセル・コードブロックと図の中身・
選んだ文字の取り消し線と文字色の 4 つを直せます（[編集モードで直す](#編集モードで直す)）。

Markdown のほかに、PlantUML と Mermaid の図のファイルと、画像のファイルも開けます
（[図と画像のファイル](#図と画像のファイル)）。

## 起動する

### そのまま実行する

展開したフォルダの実行ファイルをダブルクリックします。

引数なしで起動したとき、MarkView は次の順に `README.md` を探し、**最初に見つかったもの**を開きます。
そのファイルがあるディレクトリが、ファイルツリーの起点になります。

1. コマンドを実行したディレクトリ（カレントディレクトリ）
2. 実行ファイルが置かれているディレクトリ

ダブルクリックで起動した場合はどちらも同じ場所になるため、**実行ファイルの隣にある
`README.md`** が開きます。`readme.md` や `Readme.md` のような大文字小文字違いも対象です。

`README.md` が見つからない場合は、操作を案内する画面が出ます。エラーではありません。

> [!NOTE]
> カレントディレクトリを先に探すのは、`PATH` に置いた `MarkView` をターミナルから使うときに、
> **いま作業している場所**の README が開いてほしいためです。

### 引数を渡す

```sh
MarkView docs/design.md    # そのファイルを開き、docs/ をツリーの起点にする
MarkView docs/arch.puml    # 図のファイルや画像のファイルも同じように開ける
MarkView docs/             # docs/ を起点にし、直下の README.md を開く
MarkView --version         # バージョンを表示して終了する（ウィンドウを開かない）
MarkView --help            # 使い方を表示して終了する
```

- 引数を 2 つ以上渡した場合、2 つ目以降は無視します。
- 存在しないパスを渡してもウィンドウは開きます。本文ペインにその旨を表示します。
- 開けない種類のファイルを渡した場合も、ウィンドウは開きます。その親ディレクトリをツリーの起点にし、
  対応していない旨をステータス領域に出します。
- 知らないオプション（`--nosuch` など）を渡した場合だけ、使用方法を標準エラーへ出して
  終了コード 2 で終わります。

## 文書を開く

開く経路は 6 つです。**これ以外の方法で任意のファイルが開かれることはありません。**

| 経路 | 操作 | ツリーの起点 |
| --- | --- | --- |
| ファイル選択ダイアログ | ツールバーの開くボタン、または `Ctrl+O` | 選んだファイルの親ディレクトリに**移動する** |
| ドラッグ＆ドロップ | ウィンドウへファイルかフォルダを落とす | 落としたものの位置へ**移動する** |
| コマンドライン引数 | 上記のとおり | 引数の位置に**なる** |
| ファイルツリー | 左ペインから選ぶ（右クリックメニューの `Open` も同じ） | **変わらない** |
| 本文中のリンク | `.md` などへのリンクをクリック | **変わらない** |
| 表示履歴 | ツールバーの戻る・進むボタン、`Alt+←` / `Alt+→`、マウスのサイドボタン | **変わらない** |

開けるファイルは次の 3 種類です。

| 種類 | 拡張子 |
| --- | --- |
| Markdown | `.md` `.markdown` `.mdown` `.mkd` |
| 図のファイル（PlantUML・Mermaid） | `.puml` `.pu` `.wsd` `.plantuml` `.mmd` `.mermaid` |
| 画像のファイル | `.png` `.jpg` `.jpeg` `.gif` `.svg` `.webp` `.avif` `.bmp` `.ico` |

これ以外の拡張子のファイルは開けません。どの経路でも、開ける種類は同じです。

### ドラッグ＆ドロップの細かい動き

| 落としたもの | 動作 |
| --- | --- |
| 開けるファイル 1 つ | 表示し、その親ディレクトリを新しい起点にする |
| ディレクトリ 1 つ | そこを新しい起点にし、直下に `README.md` があれば表示する。**無ければ表示はそのまま**で、何も知らせない |
| 複数のファイル | 開けるファイルのうち**先頭の 1 つだけ**を開く。他は無視する |
| 開けないファイル | 何も変えず、対応していない旨をステータスに出す |

ドロップできるのは**ウィンドウ全体**です。本文でもサイドペインでも結果は同じです。
ドラッグしている間は、ウィンドウ全体に `Drop a file to open` と出ます。

### ファイル選択ダイアログ

フィルタは次の 5 つで、既定は `Supported files`（開けるファイルの 3 種類すべて）です。

| フィルタ | 対象 |
| --- | --- |
| `Supported files` | 下の 3 つをすべて合わせたもの |
| `Markdown files` | Markdown |
| `Diagrams` | 図のファイル |
| `Images` | 画像のファイル |
| `All files` | すべて |

開いた直後の場所は**現在のツリーの起点**です。キャンセルしても表示中の内容は変わりません。
`All files` で開けないファイルを選んだときは、表示もツリーの起点も変えず、対応していない旨をステータス領域に出します。

## 図と画像のファイル

Markdown と同じ経路で、図のファイルと画像のファイルを開けます。ウィンドウタイトル・ステータス領域のパス・
表示履歴・ツリーの強調・大きなファイルの扱い・自動の描き直しは、Markdown の文書と同じです。

### PlantUML のファイル

`.puml` `.pu` `.wsd` `.plantuml` のファイルは、**中の図を 1 つずつ、見出しを付けて上から並べます。**
見出しはアウトラインに出るので、図の多いファイルでも目的の図へすぐ移れます。

- 図は `@startuml` から `@enduml` まで（`@startmindmap` 〜 `@endmindmap` なども）で 1 つです。図の外の行は無視します。
- 見出しは、`@startuml 名前` の名前 → 図の中の最初の `title` → `Diagram 1` のような番号、の順に決まります。
- 図が 1 つも無いファイルは、ソースをそのまま等幅で出し、`No diagrams found.` と添えます。
- 取り込み用の断片（`.iuml`）は開けません。単体では図にならないためです。ツリーにも出ません。

描き方は Markdown の中の PlantUML のブロックと同じです（[対応する Markdown 記法](./markdown.md#plantuml-図)）。
外部のエディタで書きながら MarkView で開いておけば、保存するたびに図が描き直されます。

### Mermaid のファイル

`.mmd` `.mermaid` のファイルは、**ファイル全体を 1 つの図**として描きます。見出しは付きません。

- 中身が空白だけのファイルは、`No diagrams found.` と出ます。
- 図を 2 つ書いたファイルは、Mermaid の構文エラーになります（1 ファイルに 1 つの図です）。
- `.mmd` は MultiMarkdown の文書にも使われる拡張子ですが、MarkView は**拡張子で種類を決めます**。
  MultiMarkdown の文書を開くと、Mermaid の構文エラーとして表示されます。

### 画像のファイル

画像は本文ペインに**画像だけ**を出します。画像を編集する機能はありません。

- 本文の幅より大きい画像は、縦横比を保って縮小します。小さい画像は拡大しません。
  `width` / `height` の無い SVG は、本文の幅いっぱいに描きます。
- **透過している部分には市松模様を敷きます。** 透過しているかどうかが分かります。
- ステータス領域の右側に、**画像の寸法とファイルの大きさ**が出ます（`1920 × 1080 px  245 KB`）。
  `width` / `height` の無い SVG と、読み込めなかった画像では大きさだけです。
- 右上の拡大画面のボタンは**常に**出ます（[図と画像を大きく見る](#図と画像を大きく見る)）。
- 読み込めなかった画像（壊れたファイル、画素数が大きすぎて表示できない画像など）は、ファイル名を代替テキストにした
  壊れた画像の表示になります。
- **エディタで開くボタンと編集モードのボタンは、画像のファイルでは使えません**（淡色になります）。
- アウトラインには何も出ません。検索は使えますが、本文に文字が無いので一致しません。

回転・前後の画像への移動・撮影情報の表示のような、画像ビューアの機能は持ちません。
大きく見るのは、図と同じ原寸表示と拡大画面だけです。

## 画面の構成

上から「ツールバー」「コンテンツ領域」「ステータス領域」の 3 段です。
コンテンツ領域は左から **ファイルツリー → アウトライン → 本文** の順に並びます。

```text
+--------------------------------------------------------------------+
| <- -> | Open Reload | Files Outline Theme | Editor EditMode  About |
+-------------+-------------+----------------------------------------+
| Files   [Y] | Outline     |                                        |
| go_MarkView |             |  # MarkView                            |
|             |  MarkView   |                                        |
|  docs/      |   Overview  |  Markdown viewer that renders          |
|   usage.md  |   Features  |  documents the way GitHub does.        |
|  README.md  |   Install   |                                        |
|             |   Docs      |  ## Overview                           |
|             |   License   |                                        |
|             |             |  ...                                   |
+-------------+-------------+----------------------------------------+
| docs/usage.md                               UTF-8  274 lines  110% |
+--------------------------------------------------------------------+
              ^             ^
              ドラッグで幅を変えられる境界
```

図のツールバーの `<-` `->` は戻る・進むのボタン、`|` はボタンの群を分ける区切り線、
`[Y]` はファイルツリーのフィルターのボタンです。

### ツールバー

アイコンボタンが 10 個あり、**編集モードの間だけ 2 つ増えます。** 群ごとに区切り線で分かれています。左から順に、

| 群 | ボタン | 動作 | 種別 |
| --- | --- | --- | --- |
| 移動 | 戻る（左向きの矢印） | 表示履歴を戻る。戻れないときは淡色 | 実行 |
| 移動 | 進む（右向きの矢印） | 表示履歴を進む。進めないときは淡色 | 実行 |
| ファイル | 開く（フォルダ） | ファイル選択ダイアログを開く | 実行 |
| ファイル | 再読み込み | 表示中のファイルを読み直す | 実行 |
| 表示 | ファイルツリー | ファイルツリーペインの表示・非表示 | **トグル** |
| 表示 | アウトライン | アウトラインペインの表示・非表示 | **トグル** |
| 表示 | テーマ | Light / Dark を切り替える。アイコンは**切り替え先**を示す | 実行 |
| 編集 | エディタで開く（四角から矢印が出る形） | 表示中のファイルを外部エディタで開く | 実行 |
| 編集 | 編集モード（チェック付きの四角） | 編集モードの開始・終了 | **トグル** |
| 修飾 | 取り消し線（**編集モードの間だけ**） | 選んだ文字の取り消し線を付ける・外す | 実行 |
| 修飾 | 文字色（**編集モードの間だけ**） | 色の一覧を出し、選んだ文字に色を付ける | 実行 |
| — | ?（右端） | アプリケーション情報 | 実行 |

**「エディタで開く」と「編集モード」は別の機能です。** 前者は外部のエディタを起動し、
後者は MarkView の中で決まった箇所だけを直せる状態に切り替えます。
v1.1.0 までの「エディタで開く」は鉛筆のアイコンでした。v1.2.0 から鉛筆は、本文の中のコードブロックと図を
直すボタン（[コードブロックと図を直す](#コードブロックと図を直す)）に使っています。

**検索と表示倍率にボタンはありません。** キーボード（`Ctrl+F`、`Ctrl` + `+` / `-`）で操作します。

ボタンにマウスを合わせると、`Open / 開く` の形式でツールチップが出ます。
**英日併記なのは、ツールバーのボタンと、ファイルツリーのフィルターのボタン・選択肢のツールチップだけ**で、
他の UI 文言はすべて英語です。

### ペイン

- ファイルツリーの見出しは `Files`。見出しの行の右端に、フィルターのボタン（漏斗）があります
  （[並べる種類を選ぶ](#並べる種類を選ぶ)）。
- 見出しの下にツリーの起点となるディレクトリ名が出ます（マウスを乗せると絶対パスが出ます）。
- アウトラインの見出しは `Outline`。
- 境界をドラッグすると幅を変えられます。変えた幅は次回起動時に復元します。
- 両方とも非表示にできます。そのときは本文がコンテンツ領域の全幅を使います。

**本文の幅が 240 論理ピクセルを下回ると、アウトラインが一時的に隠れます。**
このときツールバーのボタンは ON のままで、設定にも記録しません。幅を戻せば自動的に戻ります。
利用者が自分で消したのか、幅が足りなくて隠れたのかを区別するためです。

ファイルツリーは自動的に隠れません。最小ウィンドウ幅（640）でも、ファイルを選ぶ手段は
残します。

### ステータス領域

| 位置 | 内容 |
| --- | --- |
| 左 | 表示中ファイルの**ツリーの起点からの相対パス**。マウスを乗せると絶対パス |
| 右 | 文字コード、総行数、表示倍率（100 % 以外のときだけ）。例: `UTF-8  120 lines  140%`。画像のファイルでは、文字コードと行数の代わりに画像の寸法とファイルの大きさ（`1920 × 1080 px  245 KB`） |

エラーや警告はここに全幅で表示され、**5 秒後に元の表示へ戻ります**。
**モーダルダイアログは出ません。** 通知先はこのステータス領域、本文中、本文ペインの
状態画面の 3 か所だけです。

## ファイルツリー

`Ctrl+Shift+E` またはツールバーのボタンで開きます。既定では非表示です。

- **開けるファイルとディレクトリだけ**が並びます。既定では Markdown と図のファイルが出て、
  画像のファイルは出ません（[並べる種類を選ぶ](#並べる種類を選ぶ)）。その他のファイルは出ません。
- ファイルは、Markdown・図・画像を見分けられるアイコンで並びます（PlantUML と Mermaid は同じ図のアイコンです）。
- 並べる種類のファイルを 1 つも含まないディレクトリは出ません。
- ディレクトリが先、ファイルが後の順です。同じ種別の中では名前順（大文字小文字を区別しない）。
  ファイルの種類では分けません。
- `node_modules` `vendor` `.git` `target` `dist` `build` と、名前が `.` で始まるディレクトリは
  表示しません。
- ディレクトリは**開いたときに初めて読み込みます**（遅延展開）。大きなツリーでも起動は遅くなりません。
- **ツリーからファイルを選んでも、起点は動きません。** 別の文書を読んでも、いま見ている
  文書群の位置を見失わないためです。起点を変えたいときは、右クリックメニューの
  `Set as tree root` / `Set parent as tree root` を使います（[ツリーの右クリックメニュー](#ツリーの右クリックメニュー)）。
- 表示中のファイルはツリー上で強調表示されます。折りたたまれた階層にある場合は自動で展開します。
  表示中のファイルの種類をフィルターで隠しているときは、強調される行がありません。

### 並べる種類を選ぶ

見出しの行の右端のボタン（漏斗）を押すと、ツリーに並べる種類を選ぶ枚が重なって開きます。

```text
+------------------------------+
| Show in tree             (X) |
| [x] Markdown (.md/.markdown/ |
|     .mdown/.mkd)             |
| [x] Diagrams (.puml/.pu/.wsd/|
|     .plantuml/.mmd/.mermaid) |
| [ ] Images (.png/.jpg/.jpeg/ |
|     .gif/.svg/.webp/.avif/   |
|     .bmp/.ico)               |
+------------------------------+
```

| 種類 | 既定 | 外せるか |
| --- | --- | --- |
| `Markdown` | 表示 | **外せません**（常に表示） |
| `Diagrams`（図のファイル） | 表示 | 外せる |
| `Images`（画像のファイル） | **非表示** | 外せる |

- チェックを切り替えると、**その場でツリーに反映します。** 展開していたディレクトリは展開したまま保ちます。
- 選んだ種類は保存し、次回の起動でも引き継ぎます（[設定と保存されるもの](./settings.md)）。
- 枚を閉じるのは `Esc`・右上の閉じるボタン・漏斗のボタンです。**外をクリックしても閉じません。**
  開いたまま、ツリーの展開や文書を開く操作ができます。
- 枚を閉じている間は、漏斗のボタンのツールチップで、いま並べている種類が分かります
  （`Filter / フィルター (Markdown, Diagrams)`）。
- **効くのはツリーの表示だけです。** 画像を隠していても、ファイル選択ダイアログ・ドロップ・リンクなどからは開けます。
- ソースコードや設定ファイルのような、開けない種類を並べる選択肢はありません。

### ツリーの右クリックメニュー

ツリーの項目を右クリックすると、その項目についてのメニューが出ます。キーボードでは、
項目にフォーカスを当てて `Shift+F10` かアプリケーションキーで開けます。

| 右クリックした所 | 項目 | 動作 |
| --- | --- | --- |
| ファイル | `Open` | クリックと同じく MarkView で開く |
| ファイル | `Open in editor...` | エディタを選ぶウィンドウを出し、**そのファイル**を外部エディタで開く（[エディタで開く](#エディタで開く)）。画像のファイルでは淡色 |
| ファイル | `Open containing folder` | そのファイルのあるフォルダを、OS のファイルマネージャで開く |
| ファイル | `Copy path` | 絶対パスをコピーする |
| ディレクトリ | `Open in file manager` | そのディレクトリを、OS のファイルマネージャで開く |
| ディレクトリ | `Set as tree root` | そのディレクトリをツリーの起点にする |
| ディレクトリ | `Copy path` | 絶対パスをコピーする |
| ツリーの起点の名前（見出しの下の行） | `Open in file manager` / `Set parent as tree root` / `Copy path` | 起点について同じ操作をする。`Set parent as tree root` は**1 つ上のディレクトリを起点にする**（ドライブやファイルシステムの根では淡色） |

- **右クリックしただけでは、項目を開かず、ツリーの強調も動きません。**
- `Open containing folder` は、フォルダを開くだけで、そのファイルを選んだ状態にはしません。
- 起点を変えても、表示中の文書・表示履歴・編集モードは変わりません。表示中の文書が新しい起点の外になれば、
  [ツリーの外を開いたとき](#ツリーの外を開いたとき) と同じ表示になります。
- ツリーに残っていたファイルが既に消えていた場合は、`File not found:` が出ます（ツリーは自動では更新されません）。
- 編集モードの間も使えます。`Open` で別の文書へ移れば、編集モードは終わります。

### ツリーを読み直したいとき

**ツリーはディレクトリの変更を監視しません。** 外部でファイルを追加・削除した場合は、
次のいずれかで読み直されます。専用の更新ボタンはありません。

- ペインを非表示にしてから、もう一度表示する
- `F5` / `Ctrl+R` で再読み込みする
- そのディレクトリを折りたたんでから、もう一度展開する
- 右クリックメニューで起点を変える
- フィルターを切り替える（展開していたディレクトリは展開したまま）

## アウトライン

`Ctrl+Shift+O` またはツールバーのボタンで開閉します。既定では表示されています。

- 本文の見出し（`#` 〜 `######`）を階層のまま並べます。
- 項目をクリックすると該当位置までスクロールします。
- **本文をスクロールすると、いま画面にある見出しが強調されます。**
- 見出しがない文書では、その旨だけを表示します。

## リンクをたどる

本文中のリンクは、行き先によって扱いが変わります。**ウィンドウの中で別のページへ
遷移することは決してありません。**

| リンク先 | 動作 |
| --- | --- |
| `.md` などの Markdown、`.puml` `.mmd` などの図のファイル | **同じウィンドウ**で開く |
| 同一文書内の `#見出し` | その位置までスクロールする |
| 他文書の `./other.md#section` | 文書を切り替えてから該当位置へ移動する |
| `.png` などの画像のファイル | **同じウィンドウ**で、画像のファイルとして開く |
| `http://` `https://` | **既定のブラウザ**で開く |
| PDF などその他のファイル（PlantUML の取り込み用の断片 `.iuml` を含む） | **OS の既定のアプリ**で開く |

- **v1.1.0 までは、画像へのリンクを OS の既定のアプリで開いていました。** v1.2.0 から MarkView で開き、
  `Alt+←` で元の文書へ戻れます。
- **Mermaid の図の中のリンク**（`click` で URL を指定したノードや、ラベルに書いたリンク）も、
  本文のリンクと同じ扱いです。
- リンクを開くのは、**マウスの左ボタンでのクリック**と、キーボード（`Tab` で移動して `Enter`）です。
  **中ボタンで押しても何も起きません。** 新しいウィンドウも開きません。
- `#見出し` のリンクは、`#user-content-見出し` と書かれていても同じ見出しへ移動します
  （[対応する Markdown 記法](./markdown.md#見出しとアンカー)）。
- 編集モードの間は、表のセルの中のリンクと、図の中のリンクを押しても移動しません
  （ダブルクリックで直し始める 1 回目で、別の文書へ移らないようにするためです。[編集モードで直す](#編集モードで直す)）。
- 既定のブラウザやアプリへ渡せなかったときは、ステータス領域に `Cannot open:` とリンク先が出ます。
  表示中の文書はそのままです。

### ツリーの外を開いたとき

リンクの行き先がファイルツリーの起点の外にある場合、文書は表示されますが

- **ツリーの起点も展開状態も変わりません**
- ツリー上の強調表示は消えます（そのファイルはツリーに無いため）
- ステータス領域に絶対パスと `(outside tree)` が出ます

`Alt+←` で戻ると強調表示が復活します。

### 履歴

ツールバーの戻る・進むボタン、`Alt+←` / `Alt+→`、マウスのサイドボタン（戻る・進む）のどれでも、
表示履歴を戻ったり進んだりできます。**戻ったときは、リンクをクリックした位置に
スクロールが復元されます。** 長い文書の途中からリンクをたどっても、読んでいた場所へ帰れます。

- 戻れない・進めないときは、ツールバーのボタンが淡色になります。
- マウスのサイドボタンは、ウィンドウのどこで押しても働きます。環境によってはサイドボタンが届かないことが
  あります。そのときはツールバーのボタンかキーボードを使ってください。
- **履歴の先の文書を開けなかったとき**（その間に削除した・名前を変えたなど）は、表示はそのままで、
  開けなかった理由がステータス領域に出ます。**その項目は履歴から取り除かれ、履歴の位置も元のまま**です。
  1 回の操作で 1 つだけ動きます（開けない項目を飛ばして、その先の文書を開くことはしません）。
- 大きなファイルの確認画面、大きすぎるファイル、表示に失敗したファイルの画面も、履歴に積まれます。
  その画面から `Alt+←` で直前の文書へ戻れます。

履歴はアプリケーションを終了すると消えます。ディスクには書きません。

## 検索する

`Ctrl+F` で検索バーを開きます。**ツールバーに検索ボタンはありません。**

検索バーは**本文ペインの右上にオーバーレイ表示**され、本文のレイアウトを押し下げません。
「入力欄」「ヒット数」「前へ」「次へ」「閉じる」で構成されます。

- 入力するそばから絞り込みます（インクリメンタル検索）。
- 大文字小文字は区別しません。部分一致です。
- 一致箇所をすべてハイライトし、**現在の 1 件だけ別の色**で示します。
- `Enter` で次へ、`Shift+Enter` で前へ移動します。移動先までスクロールします。
- 「3 / 12」のように現在位置と総ヒット数が出ます。1 件も無ければその旨を表示します。
- `Esc` で閉じ、ハイライトを解除します。

検索の対象は**本文だけ**です。アウトラインとファイルツリーは検索しません。
別の文書へ切り替えたとき、文書が描き直されたとき、表を並べ替えたときは、検索状態がリセットされます
（並べ替えると、ヒットの順が本文の順と合わなくなるためです）。

## 文字の大きさとテーマ

### 表示倍率

| 操作 | 動作 |
| --- | --- |
| `Ctrl` + `+` | 拡大 |
| `Ctrl` + `-` | 縮小 |
| `Ctrl+0` | 100 % に戻す |
| `Ctrl` + マウスホイール | 拡大・縮小 |

範囲は 50 %〜300 %、刻みは 10 % です。**本文だけ**が変わり、ツールバーやサイドペインの
文字は変わりません。100 % 以外のときは、**ステータス領域の右側**に現在の倍率が出ます
（`UTF-8  120 lines  140%`）。

**倍率は保存しません。** 起動するたびに 100 % から始まります。ウィンドウを複数開いて
別々の倍率で使えるようにするためです
（[設定と保存されるもの](./settings.md#複数同時に起動したとき) を参照）。

ツールバーに倍率のボタンはありません。

**図と画像の大きさは、倍率を変えても変わりません。** 大きく見るときは
[図と画像を大きく見る](#図と画像を大きく見る) のボタンを使います。

### テーマ

`Ctrl+Shift+T` またはツールバーのボタンで Light / Dark を切り替えます。
配色は GitHub に合わせています。

**初回起動時は OS の設定に従います。** 一度自分で切り替えると、以後はその選択を記憶し、
OS の設定が変わっても追従しなくなります。

切り替えは即座に完了します。スクロール位置・検索状態・ツリーの展開状態・倍率に加えて、
表の並べ替え・図と画像の原寸表示・編集モード・開いている編集欄もすべて保たれます。
編集モードで付けた文字色も、Dark テーマでは Dark 向けの色で描きます。

## 図と画像を大きく見る

図と画像は本文の幅に収まるよう縮小して表示されるため、大きな図では文字が読めなくなることがあります。
**Mermaid 図・PlantUML 図・画像の右上のボタン**で、大きく見られます。

| ボタン | ツールチップ | 動作 |
| --- | --- | --- |
| 左右の矢印 | `Actual size` | 本文の中で、**原寸表示と縮小表示を切り替える** |
| 四隅の枠 | `Expand` | **拡大画面**を開き、その図か画像だけを大きく表示する |

ボタンが出る対象は次のとおりです。

| 対象 | 原寸表示のボタン | 拡大画面のボタン |
| --- | --- | --- |
| Mermaid 図（描けたもの） | 縮小されているとき（原寸表示中も、戻すために出る） | 常に |
| PlantUML 図（**エラー図を含む**） | 同上 | 常に |
| 本文に埋め込んだ画像（読み込めたもの） | 同上 | 縮小されているときと原寸表示中 |
| 画像のファイル（読み込めたもの） | 同上 | **常に** |

- 埋め込んだ画像のボタンを縮小されているときに限るのは、段落の中のアイコンやバッジにまでボタンが付き、
  本文が繁雑になるのを避けるためです。画像のファイルは画像そのものを見るために開くので、拡大画面のボタンは常に出ます。
- 描けなかった図、読み込めなかった画像、描画を待っている図、数式にはボタンが出ません。
- 図の右上では、右から「コピー」「拡大画面」「原寸表示」の順に並びます。
  編集モードの間は、そのさらに左に「編集」（鉛筆）が出ます（[コードブロックと図を直す](#コードブロックと図を直す)）。
- 画像のファイルの拡大画面でも、透過している部分には市松模様を敷きます。
- **図や画像そのものをクリックしても何も起きません。** リンクで囲んだ画像でも、ボタンを押して
  リンク先へ移ることはありません。

### 原寸表示

- 本来の大きさで描き、本文の幅を超える分は**その図や画像の枠の中で横スクロール**します。
  ページ全体は横に伸びません。
- 本文の表示倍率には左右されません。
- テーマを切り替えても、ファイルが保存されて描き直されても、原寸表示のまま保たれます。
  別の文書へ切り替えると縮小表示に戻ります。

### 拡大画面

ツールバーと本文を覆って、1 つの図か画像だけを表示します。**ステータス領域は覆いません。**
開いている間に出た通知（ファイルの削除など）を見落とさないためです。

```text
+--------------------------------------------------------------------+
|  [ Fit ]  [ 1:1 ]   [ - ]  125%  [ + ]                       [x]   |
+--------------------------------------------------------------------+
|                                                                    |
|             +-----------+              +-----------+               |
|             |     A     | -----------> |     B     |               |
|             +-----------+              +-----------+               |
|                                                                    |
+--------------------------------------------------------------------+
| README.md                                        UTF-8  120 lines  |
+--------------------------------------------------------------------+
```

- 開いた時点では、**全体が収まる倍率**で中央に出ます。
- 倍率は 10 %〜1000 % で、1 段階ごとに 1.25 倍になります。
- 図は SVG のまま拡大するので、**拡大しても輪郭がぼやけません。** 画像は拡大するとぼやけます。

| 操作 | 動作 |
| --- | --- |
| マウスホイール（`Ctrl` の有無を問わない） | カーソルの位置を中心に拡大・縮小する |
| ドラッグ / 方向キー | 表示位置を動かす |
| `+` / `-`（`Ctrl` を付けても同じ） | 拡大 / 縮小 |
| `0` / `Ctrl+0` | 原寸（100 %）。`1:1` ボタンと同じ |
| `F` | 全体が収まる倍率。`Fit` ボタンと同じ |
| `Esc` | 閉じる |

- **開いている間は、`Ctrl` + ホイールや `Ctrl` + `+` / `-` を押しても本文の倍率は変わりません。**
  拡大画面の倍率が変わります。
- 開いている間、ツールバー・本文・ほかのショートカットは使えません（終了の `Ctrl+Q` / `Alt+F4` を除く）。
  ファイルのドロップだけは受け付け、別の文書に切り替わると拡大画面は閉じます。
- 開いている間に表示中のファイルが保存されると、同じ図があれば中身を差し替え、
  倍率と表示位置を保ちます。
- **図の中のリンクを押しても何も起きません。** リンクをたどるときは、拡大画面を閉じて本文で押してください。
- 右クリックメニューは出ません。
- 閉じると、本文のスクロール位置は開く前のまま、フォーカスは開いたボタンへ戻ります。

## 表を並べ替える

見出し行を除いて 2 行以上ある表では、見出しの各セルの右端に並べ替えのボタン（ツールチップ `Sort`）が出ます。

- 押すたびに、その列で **昇順 → 降順 → 元の順** と切り替わります。
  別の列のボタンを押すと、その列の昇順から始まります。
- 並べ替えている列のボタンは、昇順と降順で違うアイコンになります。ほかの列のボタンは淡色です。
- **並べ替えるのは表示だけです。ファイルは書き換えません。** 編集モードでなくても使えます。

比べ方は次のとおりです。

- 両方が数値なら、数値として比べます。桁区切りの `,` と末尾の `%` は無視します（`-1.5`、`1,234`、`10%`）。
- それ以外は文字列として比べます。大文字と小文字は区別せず、文字列の中の数字は数の大小で比べます
  （`item2` は `item10` より前）。
- 数値と文字列が混ざるときは、昇順では数値が先、降順では文字列が先になります。
- **空のセルは、昇順でも降順でも末尾**に並びます。
- 比べて等しい行は、元の順を保ちます。

そのほかの動きです。

- 並べ替えると、検索の状態はリセットされます。
- 表示中のファイルが保存されて描き直されても、並べ替えは保たれます（同じ順番の表で、列の数が変わっていないとき）。
  別の文書へ切り替えると解除されます。
- 生 HTML で書いた表（`<table>`）には、ボタンが出ません。
- 編集モードで編集欄を開いている間は、並べ替えられません（[編集欄を開いている間](#編集欄を開いている間)）。

## コピーする

コードブロックの右上に**コピーボタン**があります。

- **常に置かれています。** 既定は半透明で、マウスを重ねると不透明になります。
  消えているわけではないので、タッチ操作やキーボード操作でも使えます。
- 押すと、そのブロックの生のテキストをクリップボードへコピーします。
  シンタックスハイライトの装飾や行番号は含みません。末尾の改行 1 つは取り除きます。
- 成功するとボタンの表示が 1.5 秒ほど変わります。
- **Mermaid 図と PlantUML 図にもコピーボタンがあります。** コピーされるのは描画された
  図ではなく、**元のソース**です。描けなかった図でも同じように取り出せます。

本文の任意の範囲を選択して `Ctrl+C` でもコピーできます。

### 右クリックメニュー

右クリックすると、MarkView のメニューが出ます。**ブラウザの標準のメニュー（「戻る」「検証」など）は出ません。**

| 右クリックした場所 | 項目（上から順） |
| --- | --- |
| 本文 | `Copy link address`（**リンクの上だけ**）、`Strikethrough` と `Text color`（**編集モードの間だけ**。[取り消し線と文字色を付ける](#取り消し線と文字色を付ける)）、`Copy`、`Select all` |
| アプリケーション情報のライセンス欄 | `Copy`、`Select all` |
| 入力欄（検索バー、表のセルとコードブロックの編集欄） | `Cut`、`Copy`、`Paste`、`Select all` |
| ファイルツリーの項目と、ツリーの起点の名前 | [ツリーの右クリックメニュー](#ツリーの右クリックメニュー) を参照 |

これ以外の場所（ツールバー、ファイルツリーの項目の外、アウトライン、ステータス領域、拡大画面）では何も出ません。

- `Copy` は `Ctrl+C` と同じ内容（書式付き）をコピーします。**右クリックしても選択範囲は変わらない**ので、
  選択してから右クリックして `Copy` を選べます。
- `Copy link address` は、リンク先を **Markdown に書かれたとおりの形**でコピーします
  （`[設計](./docs/design.md#api)` なら `./docs/design.md#api`）。解決した絶対パスにはしないので、
  別の Markdown へそのまま貼れて、手元のフォルダ名（ユーザー名を含むことがある）も入りません。
- `Select all` は、本文では本文全体を、ライセンス欄と入力欄ではその中の全体を選びます。
- 使えない項目（選択範囲が無いときの `Copy` など）は、消えずに淡色で表示され、選べません。
- キーボードの `Shift+F10` かアプリケーションキーでも開けます。`↑` / `↓` で選んで `Enter` で実行し、
  `Esc` で閉じます。

## 編集中の文書を確かめる

### エディタで開く

ツールバーの**エディタで開くボタン**（四角から矢印が出る形。または `Ctrl+E`）で、表示中のファイルを
外部のエディタで開けます。このボタンは**エディタを起動するだけ**です。MarkView の中で直すのは、
隣の編集モードのボタンです（[編集モードで直す](#編集モードで直す)）。

ファイルツリーの右クリックメニューの `Open in editor...` でも、ツリーで選んだファイルを開けます
（[ツリーの右クリックメニュー](#ツリーの右クリックメニュー)）。

押すと、毎回エディタを選ぶ小さなウィンドウが出ます。見出しの下に、**開くファイルの名前**が出ます。

```
Choose an editor
design.md

  (o) Notepad
  ( ) Visual Studio Code
  ( ) Hidemaru            (not installed)

  ( ) Other...
      (no file chosen)          [ Browse ]

                    [ Cancel ]  [ Open ]
```

- インストールされているものだけが選べます。**見つからなかったものも一覧には残ります**
  （名前が出ていれば、インストールすれば使えます）。
- 一覧に無いエディタは `Other...` → `Browse` で実行ファイルを選んでください。
- `Open` を押すと、そのエディタで開きます。**選んだエディタは記憶され、次回の初期選択**に
  なります。`Enter` だけで開けます。
- 変えたくなったら、次に押したときに別のものを選ぶだけです。

**大きすぎて開けないファイルや、表示に失敗したファイルでも使えます。** MarkView が中身を見せられない状態こそ、エディタで開きたい場面だからです。ツールバーと `Ctrl+E` で開かれるのは、そのとき画面が示しているファイル（ウィンドウタイトルに出ているもの）です。

- 開くファイルは、このウィンドウを開いた時点で決まります。開いている間にドロップで文書が切り替わっても、
  ウィンドウに出ている名前のファイルを開きます。
- **画像のファイルを表示しているときと、文書を表示していないときは使えません**（ボタンが淡色になります）。
  画像をエディタで開いても、文字として読めないためです。

**毎回このウィンドウが出るのは、MarkView に設定画面が無いからです。**
「どのエディタを使うか」を尋ねる場所が他に無く、設定画面を作る代わりに、
開く操作そのものと一緒にしてあります。おかげで、変え方を探す必要がありません。

> [!NOTE]
> **端末で動くエディタ（`vim`、`nano` など）には対応していません。** 端末を持たない状態で
> 起動することになり、何も起きないまま終わります。GUI のエディタを指定してください。

エディタが起動しなかったときは、ステータス領域にその旨が出ます。表示中の文書はそのままです。
選んだエディタをアンインストールした場合は、次に押したときに**初期選択が無い状態**に戻ります。
エラーにはなりません。

### 保存すると自動で描き直します

表示中のファイルが外部で更新されると、**自動的に読み直して描き直します**。

- **スクロール位置は保たれます。** エディタで保存するたびに、いま見ている場所のまま
  仕上がりが更新されます。
- アウトラインは作り直され、ファイルツリーの展開状態は保たれます。
- 開いていた折りたたみ、表の並べ替え、図と画像の原寸表示、拡大画面、編集モードも保たれます。
  検索バーは閉じます。
- 監視するのは**表示中の 1 ファイルだけ**です。ディレクトリ全体や、文書に埋め込んだ画像のファイルは監視しません
  （画像のファイルを開いているときは、そのファイルを監視します）。
- 埋め込んだ画像のファイルを書き換えたときは、`F5` で読み直すか、文書が保存されて描き直されたときに、
  新しい画像になります。書き換えていない画像は取り直しません。
- ファイルが削除された場合、**表示は消えません。** 直前の描画をそのまま残し、
  ステータスに削除された旨を出します。

`F5` または `Ctrl+R` で手動でも読み直せます。

## 編集モードで直す

編集モードの間だけ、次の 4 つを MarkView の中で直せます。**どれも文書のブロックの数と種類を変えません。**
**それ以外（段落や見出しの文字、ブロックの追加や削除、リンク先、画像など）を直すときは
[エディタで開く](#エディタで開く) を使ってください。**

- タスクリスト（`- [ ]` / `- [x]`）のチェックボックス
- 表のセルの文字
- コードブロックと図（Mermaid・PlantUML）の中身。図のファイルも含みます
- 本文で選んだ文字の取り消し線と文字色

直すたびに、**すぐにファイルへ書き込みます。** 保存の操作はありません（セルとコードブロックは、
編集欄で確定したときに書き込みます）。

### 始める・終える

ツールバーの**編集モードのボタン**（チェック付きの四角）か `Ctrl+Shift+M` で切り替えます。

- **起動したときは、いつも編集モードではありません。** 状態を保存しないためです。
  受け取った文書を読むつもりで開いたときに、書き換えられる状態で始まることはありません。
- 編集モードの間は、ボタンが押された表示になり、本文ペインが枠で囲まれ、右下に `Edit mode` と出ます。
  ツールバーから目を離していても、書き換えられる状態だと分かります。

```text
+====================================================================+
|                                                                    |
|   # Tasks                                                          |
|                                                                    |
|   [x] step 1                                                       |
|   [ ] step 2                                                       |
|                                                                    |
|                                                     +-----------+  |
|                                                     | Edit mode |  |
|                                                     +-----------+  |
+====================================================================+
```

次のときは始められません（ボタンが淡色になります）。

| 状態 | 理由 |
| --- | --- |
| 文書を表示していない、または確認画面・エラーの画面を出している | 直す対象が表示されていない |
| 読み込みのときに不正なバイト列を `�` に置き換えた文書 | 表示とファイルの中身が一致しない |
| 表示中のファイルが削除された | 書き込み先が無い |
| 画像のファイルを表示している | 画像は編集しない |

次のときは**自動で終わります。**

- **別の文書へ切り替えたとき**（ファイルツリー・リンク・戻る / 進む・ドロップなど）。
  直すと決めた文書だけを書き換えるためです。リンクで移った先の文書が、書き換えられる状態で開くことはありません。
- 上の表の状態になったとき（読み直したら不正なバイト列を含んでいた、ファイルが削除された）。
  編集欄を開いていたときは、編集欄を閉じた時点で終わります（[編集欄を開いている間](#編集欄を開いている間)）。

ファイルが保存されて描き直されたとき、同じファイルを開き直したとき、同じ文書の中の見出しへ
移ったときは終わりません。

### チェックボックスを切り替える

編集モードの間、チェックボックスをクリックする（または `Tab` で移動して `Space` を押す）と、
オンとオフが切り替わり、ファイルへ書き込みます。

- 書き換えるのは `[ ]` / `[x]` の**括弧の中の 1 文字だけ**です。オンは `x`、オフは半角空白になります。
  `[X]`（大文字）はオンとして扱います。
- **生 HTML で書いた `<input type="checkbox">` は切り替えられません。** 編集モードの間、切り替えられる
  チェックボックスは押せる見た目になり、切り替えられないものは淡色のままです。

### 表のセルを直す

編集モードの間、直せるセルには**破線の枠**が付きます。セルを**ダブルクリック**すると、その場に
1 行の編集欄が開き、下に `Save` と `Cancel` のボタンが出ます。見出し行のセルも直せます。

- 編集欄には、表示されている文字ではなく **Markdown のソース**（`**太字**` のような記法を含む）が入っています。
- **`Enter` か `Save` で確定**してファイルへ書き込みます。**`Esc` か `Cancel` で取り消します**（何も書き込みません）。
  - **編集欄の外をクリックしても、編集欄は開いたまま残ります。** 書き込みも取り消しもしません
    （v1.1.0 までは、外をクリックすると取り消していました）。
  - 日本語入力の変換を確定する `Enter` では書き込みません。
- `|` を入力すると、表が崩れないよう `\|` として書き込みます。改行は入力できず、貼り付けた改行は半角空白になります。
- 空にしても構いません。内容が変わっていなければ書き込みません。
- 次のセルは直せません（破線が付きません）。
  - 行のセルの数が見出し行より少ないときに補われた、空のセル（直すには `|` を足すことになり、表の形が変わるため）
  - 生 HTML で書いた表（`<table>`）のセル
- 並べ替えのボタンや画像のボタンの上をダブルクリックしても、編集は始まりません。
- **編集モードの間は、セルの中のリンクを押しても移動しません。** ダブルクリックの 1 回目で文書が
  切り替わらないようにするためです。リンクをたどるときは、編集モードを終えてください。
- 表を並べ替えている間も、正しいセルを書き換えます。並べ替えの基準にしている列のセルを直しても、
  その行はその場から動きません（次にボタンを押したときに並べ直します）。
- 書き込む内容で表の形が変わる場合は、書き込みません。
  `This change would alter the document structure and was not saved.` と出て、編集欄が入力ごと開き直します。

### コードブロックと図を直す

編集モードの間、フェンス（` ``` ` か `~~~`）で囲んだコードブロックと、Mermaid・PlantUML の図の右上に、
**編集のボタン**（鉛筆）が出ます。ボタンを押すか、ブロックを**ダブルクリック**すると、その場に複数行の編集欄が
開き、下に `Save` と `Cancel` のボタンが出ます。

| 対象 | 編集欄に入るもの |
| --- | --- |
| コードブロック、Markdown の中の図 | 開きと閉じの囲いの間の行（中身） |
| PlantUML のファイルの図 | その図の `@startuml` の行から `@enduml` の行まで（図の名前も直せます） |
| Mermaid のファイル | ファイル全体 |

- 編集欄には、ハイライトの無いソースがそのまま入っています。引用やリストの中のブロックでは、
  行頭の `> ` や字下げを除いた中身が入り、書き込むときに付け直します。
- **`Ctrl+Enter` か `Save` で確定**してファイルへ書き込みます。**`Esc` か `Cancel` で取り消します。**
  `Enter` は改行です。
- `Tab` で字下げを入れ、`Shift+Tab` で外します（複数行を選んでいれば各行）。
- 編集欄の外をクリックしても、編集欄は開いたまま残ります。
- **言語指定と囲いの種類（` ``` ` か `~~~`）は変えません。** 中身の行頭に囲いと同じ並び（` ``` ` など）を
  書いたときは、ブロックが途中で閉じないよう、囲いをその並びより 1 つ長くします。
- 確定すると、すぐに入力した文字がそのまま表示され、ハイライトや図はファイルを読み直したときに戻ります。
- 次のものは直せません（編集のボタンが出ません）。字下げで書いたコードブロック、` ```math ` の数式、
  生 HTML の `<pre>`。
- 行ごとに前置き（`> ` や字下げ）が違うブロックなど、正しく書き戻せないブロックは、編集のボタンが淡色になります。
  ダブルクリックすると `This code block cannot be edited in MarkView.` と出ます。
- PlantUML のファイルで、`@enduml` を消して図がつながるなど図の数が変わる場合と、Mermaid のファイルを空白だけにする
  場合は、書き込みません。
- **編集モードの間は、図の中のリンクを押しても移動しません。** 図のボタン（コピー・原寸表示・拡大画面）は、
  これまでどおり使えます。閲覧中（編集モードでない間）は、ダブルクリックで図の中の文字を選べます。

### 取り消し線と文字色を付ける

編集モードの間、本文で文字を選び、次のどれかで取り消し線や文字色を付けられます。

| 操作 | 取り消し線 | 文字色 |
| --- | --- | --- |
| ツールバーのボタン（編集モードの間だけ出る） | 取り消し線のボタン | 文字色のボタン（色の一覧が出る） |
| 右クリックメニュー | `Strikethrough` | `Text color`（色の一覧のサブメニュー） |
| キーボード | `Ctrl+Shift+X` | （無し） |

```text
+--------------------+  +--------------+
| Strikethrough      |  | Red          |
| Text color       > |  | Orange       |
+--------------------+  | Yellow       |
| Copy               |  | Green        |
| Select all         |  | Blue         |
+--------------------+  | Purple       |
                        | Gray         |
                        +--------------+
                        | Default      |
                        +--------------+
```

- **取り消し線はトグルです。** 選んだ文字がすべて取り消し線なら外し、そうでなければ付けます。
- 色は `Red` `Orange` `Yellow` `Green` `Blue` `Purple` `Gray` の 7 色から選びます。`Default` を選ぶと色を外します。
  選んだ文字がすべて同じ色なら、一覧のその色に印が付きます。
- ファイルに書くのは、取り消し線は `<del>…</del>`、文字色は `<span style="color: #d1242f">…</span>` の形の HTML の
  タグだけです。**文字そのものは変えません。** Light テーマの色の値を書き、Dark テーマでは同じ色の Dark 向けの色で描きます。
- **GitHub では文字色が付きません**（GitHub は `style` を取り除くため、文字だけが残ります）。取り消し線は GitHub でも付きます。
- 選べるのは **1 つのブロックの中**（段落・見出し・リストの項目・表の 1 つのセル・引用や Alert の中の段落・脚注の本文）だけです。
  コードの中、数式の中、図、生 HTML のブロック、図や画像のファイルには付けられません。
- 選択の両端の空白は除きます。インラインコード・数式・画像・絵文字の一部だけを選んだときは、その全体まで広げます。
- 太字やリンクなどの中身をちょうど丸ごと選んだときは、その外側にタグを書きます（`**重要**` の全体なら
  `<del>**重要**</del>`）。日本語に接した太字の内側にタグを置くと、太字が効かなくなるためです。
- `~~…~~` や `<s>` のように**手で書いた取り消し線**は、選んだ部分だけを外せません。その取り消し線の全体を外し、
  `The whole strikethrough was removed.` と出ます。
- 分けられない、付けると太字などが効かなくなる、といった場合は書き込まず、`This formatting cannot be applied here.` と出ます。
- 使えないとき（何も選んでいない、選択が 1 つのブロックに収まっていない）は、ボタンとメニューの項目が淡色になり、
  `Ctrl+Shift+X` は何もしません。検索バーや編集欄の中では働きません。
- 付けた後も選択は残るので、取り消し線に続けて色を付けられます。

### 編集欄を開いている間

セルとコードブロックの編集欄は、**同時に 1 つだけ**開けます。開いている間は、入力を黙って捨てないよう、
次のように扱います。

| 扱い | 操作 |
| --- | --- |
| **受け付けない** | 別の文書へ切り替える操作（ファイルツリー・リンク・戻る / 進む・ドロップ・ファイル選択ダイアログ）、同じファイルの開き直し、再読み込み（`F5`）、ほかの書き込み（チェックボックス・別の編集欄・取り消し線と文字色・編集欄の外での `Ctrl+Z` / `Ctrl+Y`）、編集モードの終了、表の並べ替え |
| **編集欄を閉じるまで待つ** | ファイルが外部で保存されたときの描き直し |
| **そのまま行える** | テーマの切り替え、検索、ツリーの展開とフィルター、拡大画面を開くことなど、表示中の文書を差し替えない操作 |

- 受け付けなかったときは、`Save or cancel the open edit first.` と出て、フォーカスが編集欄へ戻ります。
- 編集欄を開いている間にファイルが外部で保存されると、`The file changed on disk. Cancel the edit to see the changes.` と
  出ます。**その間は確定できません。** 入力を写し取ってから `Cancel` で閉じると、新しい内容で描き直します。
- 編集欄を開いている間にファイルが削除されたときも、編集欄は入力ごと残ります（確定はできません）。
  編集欄を閉じた時点で編集モードが終わります。
- 書き込みに失敗したときと、書き込む内容で文書の構造が変わるため書き込まなかったときは、編集欄が入力ごと開き直します。

### 元に戻す・やり直す

| キー | 動作 |
| --- | --- |
| `Ctrl+Z` | 直前の書き込みを取り消す |
| `Ctrl+Y` / `Ctrl+Shift+Z` | 取り消した書き込みをやり直す |

- 取り消しもやり直しも、それ自体がファイルへの書き込みです。
- 1 回の操作（チェックボックス 1 つ、セル 1 つやコードブロック 1 つの確定、取り消し線や文字色 1 回）を 1 回で戻します。
- 100 操作まで戻れます。
- 編集欄や検索バーの入力欄で押したときは、その入力欄の中の取り消しになります。
- 次のときは履歴が消えます。
  - 編集モードを終えたとき
  - **ファイルが MarkView 以外で変更されたとき**。ほかの人の変更の上に、古い内容を書き戻さないためです。
- 履歴はメモリの上だけに持ち、ディスクには書きません。

### 書き込みについて

- **書き換える箇所以外は 1 バイトも変えません。** BOM、改行コード（CRLF / LF / CR）、末尾の改行、
  Front Matter、桁を揃えるための空白は、そのまま残ります。
- **外部のエディタや別の MarkView が先に保存していたら、書き込みません。** ステータス領域に
  `The file changed on disk and was not saved.` と出て、ファイルを読み直して描き直します。
  ほかの人の変更を黙って上書きしません。
- セル・コードブロック・図・取り消し線と文字色は、**書き込む内容を読み直して、文書の構造が変わらないことを
  確かめてから**書き込みます。変わるなら書き込みません。
- 読み取り専用のファイルには書き込みません。書き込めなかったときは `Failed to save:` とパスが出て、
  表示は直す前に戻ります。
- 書き込みは、同じフォルダに一時ファイルを書いてから置き換える方式です。途中で失敗しても元のファイルは
  壊れません。一時ファイルもバックアップも残しません。
  - この方式のため、**ハードリンクは切れ、Windows でファイルに個別に設定したアクセス権は引き継がれません。**
- シンボリックリンクを開いている場合は、リンク先のファイルを書き換えます。
- 書き込んだファイルは、内容と更新日時が変わります。**編集モードに入っただけ、内容の変わらない確定では、
  ファイルに何も起きません。**
- 書き込んだ後は、スクロール位置を保ったまま描き直します。

## 大きなファイル

| サイズ | 動作 |
| --- | --- |
| 10 MB 以下 | そのまま表示する |
| 10 MB 超 50 MB 以下 | 本文ペインに確認画面を出し、`Open anyway` を押すと表示する |
| 50 MB 超 | 大きすぎる旨を表示する。開く手段は出ない |

画像のファイルも、ファイルの大きさで同じように扱います（カメラの写真でも確認画面が出ることがあります）。

確認画面にはファイル名と実サイズが出ます。**モーダルダイアログではなく本文ペインに出る**ため、
確認中でもツールバー・ファイルツリー・アウトラインは普通に操作できます。
別のファイルを選べば確認は破棄されます。`Open anyway` を押すと、描き終えるまでボタンは
`Rendering...` になり、押せなくなります。

確認画面や大きすぎる旨の画面を出した時点で、ウィンドウタイトルとステータスのパス表示は対象ファイルのものに
変わり、表示履歴にも積まれます。`Alt+←` で直前の文書へ戻れます。

> [!NOTE]
> ここでの `MB` は 1 MB = 1024 × 1024 バイトです（10 MB = 10,485,760 バイト、
> 50 MB = 52,428,800 バイト）。画面上のサイズ表示も同じ換算です。

- 日本語入力の変換中は、どのショートカットも働きません。

キー割り当ての変更機能はありません。

## `.md` を MarkView に関連付ける

MarkView は**自分で関連付けを登録しません**。レジストリや `~/.local/share/applications` への
書き込みを伴い、「システムに痕跡を残さない」方針と衝突するためです
（[設定と保存されるもの](./settings.md) を参照）。

利用者が自分で設定するのは構いません。その経路で起動しても、引数付き起動として正しく動作します。

### Windows

1. 任意の `.md` ファイルを右クリックします。
2. 「プログラムから開く」→「別のプログラムを選択」を選びます。
3. 「PC でアプリを選ぶ」から `MarkView.exe` を指定します。
4. 常にこのアプリで開く場合は、チェックを入れて確定します。

### Linux

`~/.local/share/applications/markview.desktop` を作ります。

```ini
[Desktop Entry]
Type=Application
Name=MarkView
Exec=/path/to/MarkView %f
MimeType=text/markdown;
NoDisplay=false
```

```sh
update-desktop-database ~/.local/share/applications
xdg-mime default markview.desktop text/markdown
```

- うまく動かない場合は [困ったときは](./troubleshooting.md) を参照してください。
