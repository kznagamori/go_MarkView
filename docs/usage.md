## 起動する

### そのまま実行する

展開したフォルダの実行ファイルをダブルクリックします。

引数なしで起動したとき、MarkView は次の順に `README.md` を探し、**最初に見つかったもの**を開きます。
そのファイルがあるディレクトリが、ファイルツリーの起点になります。

1. コマンドを実行したディレクトリ（カレントディレクトリ）
2. 実行ファイルが置かれているディレクトリ

ダブルクリックで起動した場合はどちらも同じ場所になるため、**実行ファイルの隣にある
`README.md`** が開きます。`readme.md` や `Readme.md` のような大文字小文字違いも対象です。

`README.md` が見つからない場合は、操作を案内する画面が出ます。エラーではありません。

> [!NOTE]
> カレントディレクトリを先に探すのは、`PATH` に置いた `MarkView` をターミナルから使うときに、
> **いま作業している場所**の README が開いてほしいためです。

### 引数を渡す

```sh
MarkView docs/design.md    # そのファイルを開き、docs/ をツリーの起点にする
MarkView docs/             # docs/ を起点にし、直下の README.md を開く
MarkView --version         # バージョンを表示して終了する（ウィンドウを開かない）
MarkView --help            # 使い方を表示して終了する
```

- 引数を 2 つ以上渡した場合、2 つ目以降は無視します。
- 存在しないパスを渡してもウィンドウは開きます。本文ペインにその旨を表示します。
- 知らないオプション（`--nosuch` など）を渡した場合だけ、使用方法を標準エラーへ出して
  終了コード 2 で終わります。

## 文書を開く

開く経路は 6 つです。**これ以外の方法で任意のファイルが開かれることはありません。**

| 経路 | 操作 | ツリーの起点 |
| --- | --- | --- |
| ファイル選択ダイアログ | ツールバーの Open、または `Ctrl+O` | 選んだファイルの親ディレクトリに**移動する** |
| ドラッグ＆ドロップ | ウィンドウへファイルかフォルダを落とす | 落としたものの位置へ**移動する** |
| コマンドライン引数 | 上記のとおり | 引数の位置に**なる** |
| ファイルツリー | 左ペインから選ぶ | **変わらない** |
| 本文中のリンク | `.md` へのリンクをクリック | **変わらない** |
| 表示履歴 | `Alt+←` / `Alt+→` | **変わらない** |

扱う拡張子は `.md` `.markdown` `.mdown` `.mkd` です。

### ドラッグ＆ドロップの細かい動き

| 落としたもの | 動作 |
| --- | --- |
| Markdown ファイル 1 つ | 表示し、その親ディレクトリを新しい起点にする |
| ディレクトリ 1 つ | そこを新しい起点にし、直下に `README.md` があれば表示する |
| 複数のファイル | Markdown のうち**先頭の 1 つだけ**を開く。他は無視する |
| Markdown 以外 | 何も変えず、対応していない旨をステータスに出す |

ドロップできるのは**ウィンドウ全体**です。本文でもサイドペインでも結果は同じです。

### ファイル選択ダイアログ

フィルタは既定で `Markdown files (*.md, *.markdown, *.mdown, *.mkd)` です。
`All files (*.*)` にも切り替えられます。開いた直後の場所は**現在のツリーの起点**です。
キャンセルしても表示中の内容は変わりません。

## 画面の構成

上から「ツールバー」「コンテンツ領域」「ステータス領域」の 3 段です。
コンテンツ領域は左から **ファイルツリー → アウトライン → 本文** の順に並びます。

```text
+--------------------------------------------------------------------+
| Open  Reload  Theme  Outline  Files                          About |
+-------------+-------------+----------------------------------------+
| Files       | Outline     |                                        |
| go_MarkView |             |  # MarkView                            |
|             |  MarkView   |                                        |
|  docs/      |   Overview  |  Markdown viewer that renders          |
|   usage.md  |   Features  |  documents the way GitHub does.        |
|  README.md  |   Install   |                                        |
|             |   Docs      |  ## Overview                           |
|             |   License   |                                        |
|             |             |  ...                                   |
+-------------+-------------+----------------------------------------+
| docs/usage.md                               UTF-8  274 lines  110% |
+--------------------------------------------------------------------+
              ^             ^
              ドラッグで幅を変えられる境界
```

### ツールバー

アイコンボタンが 7 つだけです。左から順に、

| ボタン | 動作 | 種別 |
| --- | --- | --- |
| 開く | ファイル選択ダイアログを開く | 実行 |
| 再読み込み | 表示中のファイルを読み直す | 実行 |
| テーマ | Light / Dark を切り替える。アイコンは**切り替え先**を示す | 実行 |
| アウトライン | アウトラインペインの表示・非表示 | **トグル** |
| ファイルツリー | ファイルツリーペインの表示・非表示 | **トグル** |
| エディタで開く | 表示中のファイルを外部エディタで開く | 実行 |
| ?（右端） | アプリケーション情報 | 実行 |

**検索と表示倍率にボタンはありません。** キーボード（`Ctrl+F`、`Ctrl` + `+` / `-`）で操作します。

ボタンにマウスを合わせると、`Open / 開く` の形式でツールチップが出ます。
**ツールチップだけが英日併記**で、他の UI 文言はすべて英語です。

### ペイン

- ファイルツリーの見出しは `Files`。その下にツリーの起点となるディレクトリ名が出ます
  （マウスを乗せると絶対パスが出ます）。
- アウトラインの見出しは `Outline`。
- 境界をドラッグすると幅を変えられます。変えた幅は次回起動時に復元します。
- 両方とも非表示にできます。そのときは本文がコンテンツ領域の全幅を使います。

**本文の幅が 240 論理ピクセルを下回ると、アウトラインが一時的に隠れます。**
このときツールバーのボタンは ON のままで、設定にも記録しません。幅を戻せば自動的に戻ります。
利用者が自分で消したのか、幅が足りなくて隠れたのかを区別するためです。

ファイルツリーは自動的に隠れません。最小ウィンドウ幅（640）でも、ファイルを選ぶ手段は
残します。

### ステータス領域

| 位置 | 内容 |
| --- | --- |
| 左 | 表示中ファイルの**ツリーの起点からの相対パス**。マウスを乗せると絶対パス |
| 右 | 文字コード、総行数、表示倍率（100 % 以外のときだけ）。例: `UTF-8  120 lines  140%` |

エラーや警告はここに全幅で表示され、**5 秒後に元の表示へ戻ります**。
**モーダルダイアログは出ません。** 通知先はこのステータス領域、本文中、本文ペインの
状態画面の 3 か所だけです。

## ファイルツリー

`Ctrl+Shift+E` またはツールバーのボタンで開きます。既定では非表示です。

- **Markdown ファイルとディレクトリだけ**が並びます。画像やその他のファイルは出ません。
- ディレクトリが先、ファイルが後の順です。同じ種別の中では名前順（大文字小文字を区別しない）。
- `node_modules` `vendor` `.git` `target` `dist` `build` と、名前が `.` で始まるディレクトリは
  表示しません。
- ディレクトリは**開いたときに初めて読み込みます**（遅延展開）。大きなツリーでも起動は遅くなりません。
- **ツリーからファイルを選んでも、起点は動きません。** 別の文書を読んでも、いま見ている
  文書群の位置を見失わないためです。
- 表示中のファイルはツリー上で強調表示されます。折りたたまれた階層にある場合は自動で展開します。

### ツリーを読み直したいとき

**ツリーはディレクトリの変更を監視しません。** 外部でファイルを追加・削除した場合は、
次のいずれかで読み直されます。専用の更新ボタンはありません。

- ペインを非表示にしてから、もう一度表示する
- `F5` / `Ctrl+R` で再読み込みする
- そのディレクトリを折りたたんでから、もう一度展開する

## アウトライン

`Ctrl+Shift+O` またはツールバーのボタンで開閉します。既定では表示されています。

- 本文の見出し（`#` 〜 `######`）を階層のまま並べます。
- 項目をクリックすると該当位置までスクロールします。
- **本文をスクロールすると、いま画面にある見出しが強調されます。**
- 見出しがない文書では、その旨だけを表示します。

## リンクをたどる

本文中のリンクは、行き先によって扱いが変わります。**ウィンドウの中で別のページへ
遷移することは決してありません。**

| リンク先 | 動作 |
| --- | --- |
| `.md` などの Markdown | **同じウィンドウ**で開く |
| 同一文書内の `#見出し` | その位置までスクロールする |
| 他文書の `./other.md#section` | 文書を切り替えてから該当位置へ移動する |
| `http://` `https://` | **既定のブラウザ**で開く |
| 画像・PDF などその他のファイル | **OS の既定のアプリ**で開く |

### ツリーの外を開いたとき

リンクの行き先がファイルツリーの起点の外にある場合、文書は表示されますが

- **ツリーの起点も展開状態も変わりません**
- ツリー上の強調表示は消えます（そのファイルはツリーに無いため）
- ステータス領域に絶対パスと `(outside tree)` が出ます

`Alt+←` で戻ると強調表示が復活します。

### 履歴

`Alt+←` で戻り、`Alt+→` で進みます。**戻ったときは、リンクをクリックした位置に
スクロールが復元されます。** 長い文書の途中からリンクをたどっても、読んでいた場所へ帰れます。

履歴はアプリケーションを終了すると消えます。ディスクには書きません。

## 検索する

`Ctrl+F` で検索バーを開きます。**ツールバーに検索ボタンはありません。**

検索バーは**本文ペインの右上にオーバーレイ表示**され、本文のレイアウトを押し下げません。
「入力欄」「ヒット数」「前へ」「次へ」「閉じる」で構成されます。

- 入力するそばから絞り込みます（インクリメンタル検索）。
- 大文字小文字は区別しません。部分一致です。
- 一致箇所をすべてハイライトし、**現在の 1 件だけ別の色**で示します。
- `Enter` で次へ、`Shift+Enter` で前へ移動します。移動先までスクロールします。
- 「3 / 12」のように現在位置と総ヒット数が出ます。1 件も無ければその旨を表示します。
- `Esc` で閉じ、ハイライトを解除します。

検索の対象は**本文だけ**です。アウトラインとファイルツリーは検索しません。
別の文書へ切り替えると検索状態はリセットされます。

## 文字の大きさとテーマ

### 表示倍率

| 操作 | 動作 |
| --- | --- |
| `Ctrl` + `+` | 拡大 |
| `Ctrl` + `-` | 縮小 |
| `Ctrl+0` | 100 % に戻す |
| `Ctrl` + マウスホイール | 拡大・縮小 |

範囲は 50 %〜300 %、刻みは 10 % です。**本文だけ**が変わり、ツールバーやサイドペインの
文字は変わりません。100 % 以外のときは、**ステータス領域の右側**に現在の倍率が出ます
（`UTF-8  120 lines  140%`）。

**倍率は保存しません。** 起動するたびに 100 % から始まります。ウィンドウを複数開いて
別々の倍率で使えるようにするためです
（[設定と保存されるもの](./settings.md#複数同時に起動したとき) を参照）。

ツールバーに倍率のボタンはありません。

### テーマ

`Ctrl+Shift+T` またはツールバーのボタンで Light / Dark を切り替えます。
配色は GitHub に合わせています。

**初回起動時は OS の設定に従います。** 一度自分で切り替えると、以後はその選択を記憶し、
OS の設定が変わっても追従しなくなります。

切り替えは即座に完了します。スクロール位置・検索状態・ツリーの展開状態・倍率は
すべて保たれます。

## コピーする

コードブロックの右上に**コピーボタン**があります。

- **常に置かれています。** 既定は半透明で、マウスを重ねると不透明になります。
  消えているわけではないので、タッチ操作やキーボード操作でも使えます。
- 押すと、そのブロックの生のテキストをクリップボードへコピーします。
  シンタックスハイライトの装飾や行番号は含みません。末尾の改行 1 つは取り除きます。
- 成功するとボタンの表示が 1.5 秒ほど変わります。
- **Mermaid 図にもコピーボタンがあります。** コピーされるのは描画された図ではなく、
  **元の Mermaid ソース**です。

本文の任意の範囲を選択して `Ctrl+C` でもコピーできます。

## 編集中の文書を確かめる

### エディタで開く

ツールバーの**鉛筆ボタン**（または `Ctrl+E`）で、表示中のファイルを外部のエディタで開けます。
**MarkView 自身に編集機能はありません。** 開くだけです。

押すと、毎回エディタを選ぶ小さなウィンドウが出ます。

```
Choose an editor

  (o) Notepad
  ( ) Visual Studio Code
  ( ) Hidemaru            (not installed)

  ( ) Other...
      (no file chosen)          [ Browse ]

                    [ Cancel ]  [ Open ]
```

- インストールされているものだけが選べます。**見つからなかったものも一覧には残ります**
  （名前が出ていれば、インストールすれば使えます）。
- 一覧に無いエディタは `Other...` → `Browse` で実行ファイルを選んでください。
- `Open` を押すと、そのエディタで開きます。**選んだエディタは記憶され、次回の初期選択**に
  なります。`Enter` だけで開けます。
- 変えたくなったら、次に押したときに別のものを選ぶだけです。

**大きすぎて開けないファイルや、表示に失敗したファイルでも使えます。** MarkView が中身を見せられない状態こそ、エディタで開きたい場面だからです。開かれるのは、そのとき画面が示しているファイル（ウィンドウタイトルに出ているもの）です。

**毎回このウィンドウが出るのは、MarkView に設定画面が無いからです。**
「どのエディタを使うか」を尋ねる場所が他に無く、設定画面を作る代わりに、
開く操作そのものと一緒にしてあります。おかげで、変え方を探す必要がありません。

> [!NOTE]
> **端末で動くエディタ（`vim`、`nano` など）には対応していません。** 端末を持たない状態で
> 起動することになり、何も起きないまま終わります。GUI のエディタを指定してください。

エディタが起動しなかったときは、ステータス領域にその旨が出ます。表示中の文書はそのままです。
選んだエディタをアンインストールした場合は、次に押したときに**初期選択が無い状態**に戻ります。
エラーにはなりません。

### 保存すると自動で描き直します

表示中のファイルが外部で更新されると、**自動的に読み直して描き直します**。

- **スクロール位置は保たれます。** エディタで保存するたびに、いま見ている場所のまま
  仕上がりが更新されます。
- アウトラインは作り直され、ファイルツリーの展開状態は保たれます。
- 監視するのは**表示中の 1 ファイルだけ**です。ディレクトリ全体や画像は監視しません。
- ファイルが削除された場合、**表示は消えません。** 直前の描画をそのまま残し、
  ステータスに削除された旨を出します。

`F5` または `Ctrl+R` で手動でも読み直せます。

## 大きなファイル

| サイズ | 動作 |
| --- | --- |
| 10 MB 以下 | そのまま表示する |
| 10 MB 超 50 MB 以下 | 本文ペインに確認画面を出し、`Open anyway` を押すと表示する |
| 50 MB 超 | 大きすぎる旨を表示する。開く手段は出ない |

確認画面にはファイル名と実サイズが出ます。**モーダルダイアログではなく本文ペインに出る**ため、
確認中でもツールバー・ファイルツリー・アウトラインは普通に操作できます。
別のファイルを選べば確認は破棄されます。

確認画面を出した時点で、ウィンドウタイトルとステータスのパス表示は対象ファイルのものに
変わり、表示履歴にも積まれます。`Alt+←` で直前の文書へ戻れます。

> [!NOTE]
> ここでの `MB` は 1 MB = 1024 × 1024 バイトです（10 MB = 10,485,760 バイト、
> 50 MB = 52,428,800 バイト）。画面上のサイズ表示も同じ換算です。

## キーボードショートカット

| キー | 動作 |
| --- | --- |
| `Ctrl+O` | ファイルを開く |
| `Ctrl+E` | エディタで開く |
| `F5` / `Ctrl+R` | 再読み込み |
| `Ctrl+Shift+E` | ファイルツリーの表示 / 非表示 |
| `Ctrl+Shift+O` | アウトラインの表示 / 非表示 |
| `Ctrl+F` | 文書内検索を開く |
| `Enter` / `Shift+Enter` | 次 / 前の検索ヒットへ（検索バー表示中） |
| `Esc` | 検索バーを閉じる / ダイアログを閉じる |
| `Alt+←` / `Alt+→` | 表示履歴を戻る / 進む |
| `Ctrl` + `+` / `Ctrl` + `-` | 表示倍率の拡大 / 縮小 |
| `Ctrl+0` | 表示倍率を 100 % に戻す |
| `Ctrl+Shift+T` | Light / Dark テーマの切り替え |
| `Ctrl+C` | 選択範囲をコピー |
| `F1` | アプリケーション情報（バージョン・ライセンス） |
| `Ctrl+Q` / `Alt+F4` | 終了 |

キー割り当ての変更機能はありません。

## `.md` を MarkView に関連付ける

MarkView は**自分で関連付けを登録しません**。レジストリや `~/.local/share/applications` への
書き込みを伴い、「システムに痕跡を残さない」方針と衝突するためです
（[設定と保存されるもの](./settings.md) を参照）。

利用者が自分で設定するのは構いません。その経路で起動しても、引数付き起動として正しく動作します。

### Windows

1. 任意の `.md` ファイルを右クリックします。
2. 「プログラムから開く」→「別のプログラムを選択」を選びます。
3. 「PC でアプリを選ぶ」から `MarkView.exe` を指定します。
4. 常にこのアプリで開く場合は、チェックを入れて確定します。

### Linux

`~/.local/share/applications/markview.desktop` を作ります。

```ini
[Desktop Entry]
Type=Application
Name=MarkView
Exec=/path/to/MarkView %f
MimeType=text/markdown;
NoDisplay=false
```

```sh
update-desktop-database ~/.local/share/applications
xdg-mime default markview.desktop text/markdown
```

---

- 何がどう表示されるかは [対応する Markdown 記法](./markdown.md) を参照してください。
- うまく動かない場合は [困ったときは](./troubleshooting.md) を参照してください。
