# MarkView ドキュメント

MarkView の使い方をまとめたものです。目的の項目から読んでください。

| ドキュメント | 内容 |
| --- | --- |
| [使い方](./usage.md) | 起動のしかた、文書の開き方、ペイン、検索、倍率、テーマ、ショートカット |
| [対応する Markdown 記法](./markdown.md) | 見出しから Mermaid・数式まで、何がどう表示されるか |
| [記法の見本](./showcase.md) | **「こう書くと、こう出る」の実物。** MarkView で開いて確かめる |
| [設定と保存されるもの](./settings.md) | 何が保存され、何が保存されないか。保存先と消し方 |
| [困ったときは](./troubleshooting.md) | 起動しない、図が出ない、誤検知される、といった場合の対処 |

まず動かしたいだけなら [使い方](./usage.md) の「起動する」だけで足ります。
描画を一通り眺めたいなら [記法の見本](./showcase.md) を MarkView で開いてください。

## 開発者向け

上記とは別に、MarkView がどう作られているかを定めた仕様書があります。

| 文書 | 内容 |
| --- | --- |
| [仕様書](./specs/README.md) | 要求・実装・表示・テストの 5 層、20 文書 |
| [手動テスト](./tests/) | プレリリースに対して実施する手動テストの記録用 |

実装の判断はすべて仕様書に根拠があります。コードと仕様が食い違っている場合、**仕様が正**です。
